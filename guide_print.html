第一部分：水平拋體運動 (Horizontal Projectile) 題庫涵蓋：第 1 ~ 27 題
基礎運動分解 運動獨立性
$$v_x = v_0, \quad v_y = gt$$ $$x = v_0 t, \quad y = \frac{1}{2}gt^2$$
• 合速度：$v = \sqrt{v_0^2 + g^2 t^2}$
• 合位移：$S = \sqrt{x^2 + y^2}$
時間與射程變形 秒殺必背
$$t = \sqrt{\frac{2h}{g}}, \quad R = v_0 \sqrt{\frac{2h}{g}}$$ $$v_0 = R \sqrt{\frac{g}{2h}}$$
飛行時間由高度 $h$ 單獨決定！ 與初速 $v_0$ 完全無關（第 1, 2 題）。
速度角 vs 位移角 2 倍定理 常考大招
$$\tan\theta = \frac{v_y}{v_x} = \frac{gt}{v_0}$$ $$\tan\phi = \frac{y}{x} = \frac{gt}{2v_0} \implies \mathbf{\tan\theta = 2\tan\phi}$$
幾何意義：速度延長線必精確交於水平位移的中點 $(\frac{x}{2}, 0)$（第 4~6 題）。
軌跡方程式 消去時間 t
$$y = \frac{g}{2v_0^2}x^2$$
已知落點坐標 $(x_1, y_1)$，初速為：
$$v_0 = x_1 \sqrt{\frac{g}{2y_1}} \quad (\text{第 22~24 題})$$
切線與法線加速度 重力投影
$$a_T = g\sin\theta = \frac{g^2 t}{\sqrt{v_0^2 + g^2 t^2}}$$ $$a_N = g\cos\theta = \frac{g v_0}{\sqrt{v_0^2 + g^2 t^2}}$$
• $a_T$ 改變速率，$a_N$ 改變方向。
• $\vec{a} = \vec{a}_T + \vec{a}_N = \vec{g}$（恆為 $g$ 下壓）。
曲率半徑 $\rho$ 向心加速度
$$\rho = \frac{v^2}{a_N} = \frac{(v_0^2 + g^2 t^2)^{3/2}}{g v_0}$$ $$\text{拋出頂點：} \rho_0 = \frac{v_0^2}{g}$$
頂點處曲率半徑最小，之後隨時間增加而迅速擴大（第 12~15 題）。
第二部分：斜向拋體運動 (Oblique Projectile) 題庫涵蓋：第 28 ~ 60 題
同高地面三大基準定量 基石公式
$$T = \frac{2v_0\sin\theta}{g}, \ H = \frac{v_0^2\sin^2\theta}{2g}$$ $$R = \frac{v_0^2\sin 2\theta}{g} = \frac{2v_{0x}v_{0y}}{g}$$
• $T$ 與 $H$ 只與鉛直分速 $v_{0y}$ 相關。
• 水平射程 $R$ 與兩分速乘積成正比。
射程與最大高度連鎖比 秒殺神技
$$\frac{H}{R} = \frac{1}{4}\tan\theta \iff R = 4H\cot\theta$$
• $\theta = 45^\circ$ 時最大射程：$\mathbf{R_{\max} = 4H}$。
• $R = H$ 時：$\tan\theta = 4 \implies \mathbf{\theta \approx 76^\circ}$。
互餘角定理 ($\theta$ 與 $90^\circ-\theta$) 對稱特性
$$R_1 = R_2, \quad T_1 T_2 = \frac{2R}{g}$$ $$H_1 + H_2 = \frac{v_0^2}{2g}, \ R = 4\sqrt{H_1 H_2}$$
同初速同射程必為互餘角發射！高度和即為鉛直上拋高度（第 39~42 題）。
因式分解軌跡方程 (過障礙) 解題神器
$$y = x \tan\theta \left(1 - \frac{x}{R}\right)$$
題目已知通過距離 $x$、高 $y$ 的障礙並落在 $R$ 處，代入本式一秒得 $\tan\theta$！
兩度通過高度 $h$ 之時間乘積 韋達定理
$$t_1 + t_2 = T, \quad t_1 t_2 = \frac{2h}{g}$$ $$\mathbf{h = \frac{1}{2}g t_1 t_2}$$
高度 $h$ 直接由兩通過時間相乘決定，完全不需知道初速或仰角。
最高頂點之曲率半徑 頂點向心
$$\rho_{\text{頂}} = \frac{v_{\text{頂}}^2}{g} = \frac{v_0^2\cos^2\theta}{g}$$ $$\vec{v}_{\text{avg}} = v_0\cos\theta \ \hat{i}$$
最高點速率為 $v_0\cos\theta$；全程（回到同高）平均速度等於水平分速。
第三部分：斜面拋體與相對運動 (Incline & Relative Motion) 題庫涵蓋：第 61 ~ 72 題
旋轉坐標系分解法 (斜角 $\alpha$) 通用首選
$$a_{x'} = -g\sin\alpha, \ a_{y'} = -g\cos\alpha$$ $$T = \frac{2v_0\sin\beta}{g\cos\alpha}, \ H_{\perp} = \frac{v_0^2\sin^2\beta}{2g\cos\alpha}$$
$\beta$ 為與斜面夾角。垂直斜面為類鉛直上拋，求滯空時間與垂直距最快。
斜面最大射程之平分角定理 極值條件
$$\beta = \frac{90^\circ - \alpha}{2} = 45^\circ - \frac{\alpha}{2}$$ $$S_{\max} = \frac{v_0^2}{g(1 + \sin\alpha)}$$
初速度向量方向必須平分「斜面」與「鉛垂線」之夾角（第 65 題）。
垂直撞擊斜面判定條件 壓軸大招
$$v_{x'} = 0 \implies v_{0x'} - (g\sin\alpha) T = 0$$ $$\mathbf{\cot\beta = 2\tan\alpha}$$
垂直撞擊斜面代表著地時沿斜面分速減為 0（第 70 題）。
空中相遇相撞 (相對運動) 相對等速
$$\vec{a}_{\text{相對}} = \vec{g} - \vec{g} = \vec{0}$$ $$\text{空中拋體相對運動必為「等速直線」}$$
相撞充要條件：初相對速度 $\vec{v}_1 - \vec{v}_2$ 必指向初始位置連線（第 71 題）。
車載拋體 (慣性系轉換) 時間不變
$$T_{\text{車內}} = T_{\text{地面}} = \frac{2v_0}{g}$$ $$H_{\text{車內}} = H_{\text{地面}} = \frac{v_0^2}{2g}$$
車內鉛直上拋，地面看為斜拋。停留時間與最大高度量測完全相同（第 72 題）。
大三角形正弦定理法 向量閉合
$$\vec{r} = \vec{v}_0 t + \frac{1}{2}\vec{g}t^2$$ $$\frac{s}{\sin\angle 1} = \frac{v_0 t}{\sin\angle 2} = \frac{\frac{1}{2}gt^2}{\sin\angle 3}$$
位移分解為慣性位移與自由落體位移，免坐標投影求解幾何關係（第 66~68 題）。

第四部分：全單元 72 題型分類歸納矩陣 8 大題型模型速查
題型模型 題號涵蓋 物理情境與題目特徵 核心破題 SOP 秒殺秘訣 / 公式
模型 1平拋定量 01, 02, 07 給高度求時間、射程、飛機投彈轟擊相向運動船隻。 ① $t = \sqrt{2h/g}$ 求下落時間；② 水平射距 $x = (v_{\text{機}}+v_{\text{船}})t$。 時間高度獨力決定；相對前進速率相加。
模型 2夾角變換 03~06, 31, 35, 36 出現「速度夾角 $\theta$」、「位移夾角 $\phi$」或求通過兩不同傾角點高度差。 ① 水平分速 $v_0$ 永不變，$v_y = v_0\tan\theta$；② 兩點高度差 $h = \frac{v_0^2(\tan^2\theta_2 - \tan^2\theta_1)}{2g}$。 $\tan\theta = 2\tan\phi$（速度角正切是位移角的 2 倍）。
模型 3加速度/曲率 09~15, 37 求任意時刻之切向 $a_T$、法向 $a_N$ 或軌跡曲率半徑 $\rho$。 ① 求該時刻速度夾角 $\theta$；② $g$ 向下投影：$a_T = g\sin\theta, a_N = g\cos\theta$；③ $\rho = \frac{v^2}{a_N}$。 拋出點/頂點曲率半徑最小：$\rho = \frac{v^2}{g}$。
模型 4斜面階梯 08, 16~21 自斜坡頂拋出落回斜面、小球在階梯台階逐階彈落。 ① 落回斜面位移比 $\frac{y}{x} = \tan\alpha \implies t = \frac{2v_0\tan\alpha}{g}$；② 階梯邊緣連線視為斜坡，階數向上取整。 離斜面最遠處瞬時速度平行於斜面（半程時間）。
模型 5障礙物通關 22~24, 32, 33 求軌跡拋物線方程、小球恰越過球網或高牆落於底線。 ① 平拋用 $y = \frac{g}{2v_0^2}x^2$；② 斜拋越過高牆必用因式分解型：$y = x\tan\theta(1 - x/R)$。 切勿列時間 $t$ 聯立，直接用因式分解型一步得角度。
模型 6斜拋三大極值 28~30, 34, 38~45, 50, 51 同初速不同仰角同射程、射程與最大高度比值、兩度過高度 $h$。 ① 同初速同射程必為互餘角（$\theta_1+\theta_2 = 90^\circ$）；② $H/R = \frac{1}{4}\tan\theta$；③ 兩度過高度 $h = \frac{1}{2}gt_1 t_2$。 $45^\circ$ 時 $R_{\max} = 4H$；$R=H$ 時 $\theta \approx 76^\circ$。
模型 7斜面斜拋著陸 46~49, 61~70 沿斜面上拋求最大射程、要求拋體以垂直方向砸入斜面。 ① 旋轉坐標軸分解重力 $g\sin\alpha, g\cos\alpha$；② 最大射程發射角平分夾角；③ 垂直撞擊沿斜面分速為 0。 垂直著陸判定：$\cot\beta = 2\tan\alpha$。
模型 8相對運動/車載 25~27, 71, 72 空中雙球同時相遇、獵人打猴子、等速前進車內鉛直上拋。 ① 相對加速度為 0，相對運動必為「等速直線」；② 車載拋體滯空時間與上升高度在車內車外測量完全一致。 空中相撞瞄準初始連線方向即可命中。
第五部分：條件反射思維導航與四大致命避坑警示 考場秒殺心法
⚡ 題目關鍵字 $\rightarrow$ 條件反射速查 大腦第一反應
• 見高度 $h$ $\implies$ 自由落體求時間 $t = \sqrt{2h/g}$，不理會水平初速。
• 見速度夾角 $\theta$ $\implies$ 水平 $v_0$ 永不變，$v_y = v_0\tan\theta$。
• 見位移夾角與速度夾角 $\implies$ 立刻反射 $\tan\theta_{\text{速}} = 2\tan\phi_{\text{位}}$。
• 見切向/法向加速度 $\implies$ 重力下壓向量分解 $a_T = g\sin\theta, a_N = g\cos\theta$。
• 見越過障礙落地 $\implies$ 必用 $y = x\tan\theta(1 - x/R)$ 一步得仰角。
• 見同初速同射程 $\implies$ 互餘角 $\theta$ 與 $90^\circ-\theta$，$T_1 T_2 = 2R/g$。
• 見斜面上拋 $\implies$ 旋轉坐標軸分解，垂直斜面為等減速上拋。
🚫 高中生考場常踩四大致命失分陷阱 嚴防丟分
1. 混淆「速度夾角」與「位移夾角」：
位移角是位置比（$y/x$），速度角是分速比（$v_y/v_x$），兩者正切值永遠相差 2 倍！題目問「落地速度夾角」絕不能用高度除以射程。
2. 誤以為「最高頂點加速度為 0」：
最高點鉛直速度為 0，但合加速度恆為重力加速度 $\vec{g}$（鉛直向下）。
3. 斜面問題死板使用水平/鉛直分解：
會產生聯立高階二次方程；旋轉坐標軸（垂直與沿斜面）為唯一降維解法。
4. 空中雙球相遇死算時間聯立：
立即切換為相對運動視角，相對加速度為 0，等速直線連線一目了然。
