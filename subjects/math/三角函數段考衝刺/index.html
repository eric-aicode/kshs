題型 1：和差角與倍半角之角度湊合與求值

核心思維：觀測特殊角的加減關係（如 $75^\circ = 45^\circ+30^\circ$, $15^\circ = 45^\circ-30^\circ$）或兩未知角之和與差（如 $\angle A = (\alpha+\beta) - \beta$）。正切和角公式 $\tan(\alpha+\beta) = \frac{\tan\alpha+\tan\beta}{1-\tan\alpha\tan\beta}$ 常考斜率與兩線夾角 $\tan\theta = |\frac{m_1-m_2}{1+m_1m_2}|$。

題型 2：條件對稱式（平方和與聯立消元）

核心思維：若已知 $\sin\alpha \pm \sin\beta$ 與 $\cos\alpha \pm \cos\beta$，兩式分別平方後相加，即可利用 $\sin^2+\cos^2=1$ 迅速求出 $\cos(\alpha \mp \beta)$。

題型 3：三角形形狀判定與幾何極值應用

核心思維：利用 $A+B+C = 180^\circ \implies \sin C = \sin(A+B)$，$\cos C = -\cos(A+B)$。若 $\sin 2A = \sin 2B \implies 2A=2B$ 或 $2A+2B=180^\circ$（即等腰或直角）。

題型 4：三角函數圖形伸縮平移與參數逆推

核心公式：$y = a\sin(bx + c) + d$。振幅 $a = \frac{M-m}{2}$，中心線 $d = \frac{M+m}{2}$，週期 $T = \frac{2\pi}{|b|}$。平移量判定務必提取 $b$：$y = a\sin[b(x + \frac{c}{b})] + d$。

題型 5：超越方程式實根個數（數形結合）

核心思維：將方程式拆為 $y = \sin x$ 與 $y = \frac{x}{k}$。抓住直線在邊界 $y = \pm 1$ 時的 $x$ 範圍，在該範圍內分析正弦波峰與直線的高度交叉次數。

題型 6：正餘弦一次疊合（全域 vs. 閉區間極值）

核心公式：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\phi)$。若 $x \in [\alpha, \beta]$，務必先確定複合角 $x+\phi$ 的區間，找出正弦在該區間的真正最高點與最低點。

題型 7：倍角降次型二次疊合

降次公式：$\sin^2 x = \frac{1-\cos 2x}{2}$, $\cos^2 x = \frac{1+\cos 2x}{2}$, $\sin x\cos x = \frac{\sin 2x}{2}$。將二次式降為 $2x$ 的一次疊合式求極值。

題型 8：對稱換元型與分式斜率型極值

換元公式：令 $t = \sin x + \cos x \in [-\sqrt{2}, \sqrt{2}]$，則 $\sin x\cos x = \frac{t^2-1}{2}$，轉為 $t$ 的二次函數配方。
分式型：$y = \frac{a\sin x + b}{\cos x + c}$，交叉相乘轉為 $a\sin x - y\cos x = cy - b$，疊合後利用 $|\sin(x-\phi)| \le 1$ 解 $y$ 的二次不等式。

1. 角度換算與和差角 5 分
求 $\sin 107^\circ \cos 47^\circ - \sin 313^\circ \cos 73^\circ$ 之值為何？
【正解】：(D)

解析：
利用廣義角化簡：$\sin 107^\circ = \sin(180^\circ - 73^\circ) = \sin 73^\circ$；$\sin 313^\circ = \sin(360^\circ - 47^\circ) = -\sin 47^\circ$。
原式 $= \sin 73^\circ\cos 47^\circ - (-\sin 47^\circ)\cos 73^\circ = \sin 73^\circ\cos 47^\circ + \cos 73^\circ\sin 47^\circ = \sin(73^\circ + 47^\circ) = \sin 120^\circ = \frac{\sqrt{3}}{2}$。

2. 圖形伸縮平移 5 分
函數 $y = 4\cos(\frac{x}{2} - \frac{\pi}{6})$ 之圖形是由 $y = 4\cos\frac{x}{2}$ 之圖形沿 $x$ 軸正方向平移 $h$ 單位而得，則 $h$ 之最小正值為何？
【正解】：(B)

解析：
將自變數提取 $x$ 之係數 $\frac{1}{2}$：$y = 4\cos[\frac{1}{2}(x - \frac{\pi}{3})]$。
故圖形是由 $y = 4\cos\frac{x}{2}$ 向右（$x$ 軸正方向）平移 $\frac{\pi}{3}$ 單位。

3. 閉區間疊合極值 5 分
設 $-\frac{\pi}{6} \le x \le \frac{\pi}{3}$，則函數 $y = \sqrt{3}\sin x - \cos x$ 的最大值與最小值分別為何？
【正解】：(B)

解析：
疊合：$y = 2\sin(x - \frac{\pi}{6})$。
角度範圍：$-\frac{\pi}{3} \le x - \frac{\pi}{6} \le \frac{\pi}{6}$。正弦函數在此區間單調遞增：
最大值在 $x = \frac{\pi}{3}$ 處：$2\sin(\frac{\pi}{6}) = 1$；最小值在 $x = -\frac{\pi}{6}$ 處：$2\sin(-\frac{\pi}{3}) = -\sqrt{3}$。

4. 超越方程實根個數 5 分
方程式 $3\pi \sin x = x$ 在實數範圍內共有幾個實根？
【正解】：(C)

解析：
改寫為 $\sin x = \frac{x}{3\pi}$，考慮直線 $y = \frac{x}{3\pi}$ 與正弦波的交點：
當 $|x| > 3\pi$ 時，直線 $|y| > 1$ 不再相交。
- 原點 $(0,0)$ 算 1 個。
- 正半軸：在 $(0, \pi)$ 波峰交 1 個；在 $(2\pi, 3\pi)$ 波峰（最高點 $2.5\pi$ 處直線高度 $5/6 < 1$）交 2 個。正半軸共 3 個交點。
- 負半軸：對稱亦有 3 個交點。
總交點數 $= 3 + 1 + 3 = 7$ 個。

5. 正弦倍角與範圍判定 6 分
設 $\frac{\pi}{4} < \theta < \frac{3\pi}{4}$，請選出所有正確的選項：
【正解】：(B)(C)

解析：
當 $\theta \in (\frac{\pi}{4}, \frac{3\pi}{4})$ 時：
- (A) $\sin\theta \in (\frac{\sqrt{2}}{2}, 1]$，錯誤。
- (B) $\cos(-\theta) = \cos\theta \in (-\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2})$，正確。
- (C) $\sin\theta\cos\theta = \frac{1}{2}\sin 2\theta$。因 $2\theta \in (\frac{\pi}{2}, \frac{3\pi}{2}) \implies \sin 2\theta \in [-1, 1) \implies \frac{1}{2}\sin 2\theta \in [-\frac{1}{2}, \frac{1}{2})$，完全落在範圍內，正確。
- (D) $\tan\theta > 1$ 或 $\tan\theta < -1$，錯誤。
- (E) $\frac{\theta}{2} \in (\frac{\pi}{8}, \frac{3\pi}{8})$，$\sin\frac{\pi}{8} < \frac{1}{2}$，錯誤。

6. 圖形性質綜合分析 6 分
考慮函數 $f(x) = 2\sin 3x$，請選出所有正確的選項：
【正解】：(A)(B)(C)(D)

解析：
- (A) 振幅為 2，值域 $[-2, 2]$，正確。
- (B) $f(\frac{\pi}{6}) = 2\sin\frac{\pi}{2} = 2$，正確。
- (C) 週期 $T = \frac{2\pi}{3}$，正確。
- (D) $f(\frac{\pi}{2}) = 2\sin\frac{3\pi}{2} = -2$ 為波谷極小值點，故鉛直線 $x = \frac{\pi}{2}$ 為圖形對稱軸，正確。
- (E) $f(2) = 2\sin(6 \text{ rad})$。$6 \text{ rad} \approx 343.8^\circ$ 位於第四象限，正弦值為負，錯誤。

7. 絕對值三角函數 6 分
考慮函數 $f(x) = |\sin x| + |\cos x|$，請選出所有正確的選項：
【正解】：(A)(B)(E)

解析：
- (A) $f(-x) = |-\sin x| + |\cos x| = f(x)$，正確。
- (B)(C) $f^2(x) = 1 + |\sin 2x|$。因 $0 \le |\sin 2x| \le 1 \implies 1 \le f^2(x) \le 2 \implies 1 \le f(x) \le \sqrt{2}$。最大值 $\sqrt{2}$，最小值 $1$，故 (B) 正確、(C) 錯誤。
- (D)(E) $f(x+\frac{\pi}{2}) = |\cos x| + |-\sin x| = f(x)$，最小正週期為 $\frac{\pi}{2}$。故 (E) 正確、(D) 錯誤。

8. 幾何面積與週期性 6 分
令 $A(a)$ 表示 $x$ 軸、$y$ 軸、直線 $x = a$（$a > 0$）與曲線 $y = 2 + \sin x$ 所圍成的面積。請選出所有正確的選項：
【正解】：(C)(E)

解析：
正弦波以 $2\pi$ 為週期上下對稱起伏。在一個完整週期 $[0, 2\pi]$ 內，正半波增量與負半波減量剛好抵消，平均高度恆為 2。
- $A(2\pi) = 2 \times 2\pi = 4\pi$；$A(4\pi) = 2 \times 4\pi = 8\pi = 2A(2\pi)$，(C) 正確。
- 在 $[2\pi, 3\pi]$ 與 $[0, \pi]$ 為波峰區段，面積皆為 $2\pi + 2$；在 $[3\pi, 4\pi]$ 與 $[\pi, 2\pi]$ 為波谷區段，面積皆為 $2\pi - 2$。
故 $A(4\pi) - A(3\pi) = A(2\pi) - A(\pi) = 2\pi - 2$，(E) 正確。

9. 條件對稱式求值 6 分
已知 $\sin\alpha - \sin\beta = \frac{1}{2}$，$\cos\alpha + \cos\beta = \frac{1}{3}$，則 $\cos(\alpha+\beta) = $    。
【正解】：$-\frac{59}{72}$

解析：

10. 圖形參數逆推 6 分
某餘弦函數 $y = a\cos bx + c$（其中 $a, b, c$ 均為正數）的圖形波峰位於 $(0, 3)$，相鄰的波谷位於 $(\frac{\pi}{3}, -1)$，則數對序組 $(a, b, c) = $    。
【正解】：$(2, 3, 1)$

解析：
- 振幅 $a = \frac{3 - (-1)}{2} = 2$。
- 中心線 $c = \frac{3 + (-1)}{2} = 1$。
- 波峰到相鄰波谷為半週期：$\frac{T}{2} = \frac{\pi}{3} \implies T = \frac{2\pi}{3}$。
- 由 $\frac{2\pi}{b} = \frac{2\pi}{3} \implies b = 3$。
故 $(a, b, c) = (2, 3, 1)$。

11. 觀賞壁畫最大視角應用 6 分
博物館有一幅高 $9$ 公尺的壁畫垂直掛在牆上，其下緣距離地面 $4.7$ 公尺。某生眼睛距離地面 $1.7$ 公尺，若他站在離牆 $x$ 公尺處觀賞畫作可得最大視角 $\theta$，則數對 $(x, \tan\theta) = $    。
【正解】：$(6, \frac{3}{4})$

解析：
視線相對於畫作下緣高差為 $4.7 - 1.7 = 3$ 公尺，上緣高差為 $3 + 9 = 12$ 公尺。
$\tan\theta = \tan(\alpha - \beta) = \frac{\frac{12}{x} - \frac{3}{x}}{1 + \frac{36}{x^2}} = \frac{9}{x + \frac{36}{x}}$。
利用算幾不等式：$x + \frac{36}{x} \ge 2\sqrt{36} = 12$，等號成立於 $x = \frac{36}{x} \implies x = 6$。
此時 $\tan\theta = \frac{9}{12} = \frac{3}{4}$。數對為 $(6, \frac{3}{4})$。

12. 二次項降次與疊合極值 6 分
求函數 $f(x) = 2\sin^2 x + 2\sqrt{3}\sin x\cos x$ 的最大值為    ，最小值為    。
【正解】：最大值 $3$，最小值 $-1$

解析：
利用半角與倍角公式降次：
$2\sin^2 x = 1 - \cos 2x$，$2\sqrt{3}\sin x\cos x = \sqrt{3}\sin 2x$。
整理得 $f(x) = \sqrt{3}\sin 2x - \cos 2x + 1$。
疊合：$\sqrt{3}\sin 2x - \cos 2x = 2\sin(2x - \frac{\pi}{6})$。
故 $f(x) = 2\sin(2x - \frac{\pi}{6}) + 1$。
最大值為 $2(1) + 1 = 3$，最小值為 $2(-1) + 1 = -1$。

13. 對稱換元型極值 6 分
設 $f(x) = \sin x + \cos x + \sin x\cos x$，則 $f(x)$ 的最小值為    。
【正解】：$-1$

解析：
令 $t = \sin x + \cos x = \sqrt{2}\sin(x+\frac{\pi}{4}) \implies t \in [-\sqrt{2}, \sqrt{2}]$。
平方得 $t^2 = 1 + 2\sin x\cos x \implies \sin x\cos x = \frac{t^2-1}{2}$。
原式代入配方：$f(t) = t + \frac{t^2-1}{2} = \frac{1}{2}(t+1)^2 - 1$。
拋物線頂點對稱軸在 $t = -1$，因為 $-1 \in [-\sqrt{2}, \sqrt{2}]$，故當 $t = -1$（例如 $x = \pi$）時，取得最小值 $f(-1) = -1$。

14. 分式型疊合求極值 6 分
求函數 $y = \frac{3\sin x + 2}{\cos x + 2}$ 的最大值為    。
【正解】：$\frac{4+\sqrt{31}}{3}$

解析：
交叉相乘移項：$3\sin x - y\cos x = 2y - 2$。
左式疊合為 $\sqrt{y^2+9}\sin(x-\phi)$。
因為 $|\sin(x-\phi)| \le 1 \implies \frac{(2y-2)^2}{y^2+9} \le 1 \implies 4y^2 - 8y + 4 \le y^2 + 9$。
整理得 $3y^2 - 8y - 5 \le 0$。公式解方程 $3y^2-8y-5=0 \implies y = \frac{8 \pm \sqrt{64-4(3)(-5)}}{6} = \frac{8 \pm 2\sqrt{31}}{6} = \frac{4 \pm \sqrt{31}}{3}$。
故最大值為 $\frac{4+\sqrt{31}}{3}$。

15. 直角三角形幾何極值 10 分
直角三角形 $ABC$ 中，$\angle C = 90^\circ$，斜邊長 $\overline{AB} = 4$。
(1) 試求三角形 $ABC$ 周長的最大值。（5分）
(2) 試求三角形 $ABC$ 面積的最大值。（5分）
【正解】：(1) $4 + 4\sqrt{2}$ ； (2) $4$

解析：
設 $\angle A = \theta$（$0 < \theta < \frac{\pi}{2}$），則兩股長分別為 $\overline{AC} = 4\cos\theta$，$\overline{BC} = 4\sin\theta$。

(1) 周長 $P(\theta)$：
$P(\theta) = 4 + 4\sin\theta + 4\cos\theta = 4 + 4\sqrt{2}\sin(\theta + \frac{\pi}{4})$。
當 $\theta = \frac{\pi}{4}$ 時，$\sin(\frac{\pi}{4}+\frac{\pi}{4}) = 1$，周長達最大值 $4 + 4\sqrt{2}$。

(2) 面積 $A(\theta)$：
$A(\theta) = \frac{1}{2}(4\cos\theta)(4\sin\theta) = 8\sin\theta\cos\theta = 4\sin 2\theta$。
當 $2\theta = \frac{\pi}{2} \implies \theta = \frac{\pi}{4}$ 時，$\sin 2\theta = 1$，面積達最大值 $4$。

16. 吊車懸臂與差角測量 10 分
有一吊車垂直車身高 $\overline{AB} = 7$ 公尺（$A$ 在地面），懸吊臂長 $\overline{BC} = 25$ 公尺最初停放於水平地面上。
當懸吊臂繞 $B$ 點旋轉舉高至 $D$ 點時（$A, B, C, D$ 在同一垂直平面上且臂長不變 $\overline{BD} = 25$ 公尺），量得懸吊臂末端移動直線距離 $\overline{CD} = 30$ 公尺。
試求此時懸吊臂頂端 $D$ 點距離地面的垂直高度為多少公尺？
【正解】：$\frac{702}{25}$ 公尺（或 $28.08$ 公尺）

解析：
1. 在等腰 $\triangle BCD$ 中，$\overline{BC} = \overline{BD} = 25$，底邊 $\overline{CD} = 30$。
過 $B$ 作垂線平分底邊，半角 $\angle DCB$ 滿足 $\cos\angle DCB = \frac{15}{25} = \frac{3}{5} \implies \sin\angle DCB = \frac{4}{5}$。
2. 在直角 $\triangle ABC$ 中，$\overline{AB} = 7$，$\overline{BC} = 25 \implies \overline{AC} = \sqrt{25^2-7^2} = 24$。
故 $\sin\angle ACB = \frac{7}{25}$，$\cos\angle ACB = \frac{24}{25}$。
3. $D$ 點對地面的視線仰角為 $\angle DCA = \angle DCB + \angle ACB$。
由正弦和角公式：
$\sin\angle DCA = \sin\angle DCB \cos\angle ACB + \cos\angle DCB \sin\angle ACB = (\frac{4}{5})(\frac{24}{25}) + (\frac{3}{5})(\frac{7}{25}) = \frac{96+21}{125} = \frac{117}{125}$。
4. $D$ 點垂直於地面的高度為 $h = \overline{CD} \times \sin\angle DCA = 30 \times \frac{117}{125} = \frac{702}{25} = 28.08$ 公尺。
