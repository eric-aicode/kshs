## 核心重點整理

### 一、週期函數與週期變換
1. **週期函數定義**：若存在一非零常數 $p$，使得函數 $f(x)$ 對於定義域內任意 $x$ 恆成立 $f(x+p) = f(x)$，則稱 $f(x)$ 為週期函數。滿足此條件之最小正數 $p$ 稱為 $f(x)$ 的**最小正週期**（簡稱週期）。
2. **週期變換公式**：
   - 若 $f(x)$ 的週期為 $p$，則 $f(ax+b) + k$ （其中 $a \neq 0$）的週期為 $\frac{p}{|a|}$。
   - 水平伸縮不影響振幅，垂直伸縮與平移不影響週期。

### 二、基本三角函數性質與特徵表

| 三角函數 | 定義域 | 值域 | 週期 | 對稱性 |
| :--- | :--- | :--- | :--- | :--- |
| $y = \sin x$ | $\mathbb{R}$ | $[-1, 1]$ | $2\pi$ | 對稱於原點（奇函數） |
| $y = \cos x$ | $\mathbb{R}$ | $[-1, 1]$ | $2\pi$ | 對稱於 $y$ 軸（偶函數） |
| $y = \tan x$ | $\{x \in \mathbb{R} \mid x \neq k\pi + \frac{\pi}{2}, k \in \mathbb{Z}\}$ | $\mathbb{R}$ | $\pi$ | 對稱於原點（奇函數） |
| $y = \cot x$ | $\{x \in \mathbb{R} \mid x \neq k\pi, k \in \mathbb{Z}\}$ | $\mathbb{R}$ | $\pi$ | 對稱於原點（奇函數） |
| $y = \sec x$ | $\{x \in \mathbb{R} \mid x \neq k\pi + \frac{\pi}{2}, k \in \mathbb{Z}\}$ | $(-\infty, -1] \cup [1, \infty)$ | $2\pi$ | 對稱於 $y$ 軸（偶函數） |
| $y = \csc x$ | $\{x \in \mathbb{R} \mid x \neq k\pi, k \in \mathbb{Z}\}$ | $(-\infty, -1] \cup [1, \infty)$ | $2\pi$ | 對稱於原點（奇函數） |

## 例題與類題

### 例題 1
- **題目**：比較 $\sin 1, \sin 2, \sin 3$ 之大小。
- **答案**：$\sin 3 < \sin 1 < \sin 2$
- **解析**：
  1. 將弧度換算為角度參考值：
     - $1 \text{ 弧度} \approx 57.3^\circ \Rightarrow \sin 1 \approx \sin 57.3^\circ$
     - $2 \text{ 弧度} \approx 114.6^\circ \Rightarrow \sin 2 = \sin(180^\circ - 114.6^\circ) = \sin 65.4^\circ$
     - $3 \text{ 弧度} \approx 171.9^\circ \Rightarrow \sin 3 = \sin(180^\circ - 171.9^\circ) = \sin 8.1^\circ$
  2. 在第一象限 $0^\circ < 8.1^\circ < 57.3^\circ < 65.4^\circ < 90^\circ$ 範圍內，正弦函數 $\sin\theta$ 為嚴格遞增函數。
  3. 比較正弦值：$\sin 8.1^\circ < \sin 57.3^\circ < \sin 65.4^\circ$，故 $\sin 3 < \sin 1 < \sin 2$。

#### 類題 1
- **題目**：比較 $\tan 1, \tan 2, \tan 3$ 之大小。
- **答案**：$\tan 1 > \tan 3 > \tan 2$
- **解析**：
  1. 分析各角度所在象限與正負號：
     - $1 \text{ 弧度} \approx 57.3^\circ$（第一象限，正值，且 $\tan 57.3^\circ > \tan 45^\circ = 1$）
     - $2 \text{ 弧度} \approx 114.6^\circ$（第二象限，負值，$\tan 114.6^\circ = -\tan 65.4^\circ \approx -2.18$）
     - $3 \text{ 弧度} \approx 171.9^\circ$（第二象限，負值，$\tan 171.9^\circ = -\tan 8.1^\circ \approx -0.14$）
  2. 正數必大於負數；負數中角度越靠近 $180^\circ$（$\pi$）者，正切值越接近 0（即數值較大）。
  3. 得 $\tan 1 > 0 > \tan 3 > \tan 2$。

### 例題 2
- **題目**：已知 $\frac{\pi}{3} \le \theta \le \frac{5\pi}{6}$，則 $y = 2\sin^2\theta + 2\sin\theta + 1$ 的最小值為多少？
- **答案**：$\frac{5}{2}$
- **解析**：
  1. 當 $\theta \in [\frac{\pi}{3}, \frac{5\pi}{6}]$ 時，分析正弦值範圍：
     - $\sin\frac{\pi}{3} = \frac{\sqrt{3}}{2} \approx 0.866$
     - $\sin\frac{\pi}{2} = 1$ （最大值）
     - $\sin\frac{5\pi}{6} = \frac{1}{2}$ （最小值）
     - 故 $\frac{1}{2} \le \sin\theta \le 1$。
  2. 令 $t = \sin\theta$，將原式配方：
     $$y = 2t^2 + 2t + 1 = 2\left(t + \frac{1}{2}\right)^2 + \frac{1}{2}$$
  3. 二次函數開口向上，對稱軸為 $t = -\frac{1}{2}$。因為 $t \in [\frac{1}{2}, 1]$ 位於對稱軸右側（遞增區間），故當 $t = \frac{1}{2}$ 時，$y$ 有最小值：
     $$y_{\min} = 2\left(\frac{1}{2}\right)^2 + 2\left(\frac{1}{2}\right) + 1 = \frac{1}{2} + 1 + 1 = \frac{5}{2}$$

#### 類題 2
- **題目**：設 $\frac{\pi}{6} \le x \le \frac{7\pi}{6}$，$y = \cos^2 x - 4\sin x - 3$，求 $y$ 的最小值。
- **答案**：$-7$
- **解析**：
  1. 利用平方關係 $\cos^2 x = 1 - \sin^2 x$ 化簡：
     $$y = (1 - \sin^2 x) - 4\sin x - 3 = -\sin^2 x - 4\sin x - 2$$
  2. 當 $x \in [\frac{\pi}{6}, \frac{7\pi}{6}]$ 時，$\sin x$ 的最小值為 $\sin\frac{7\pi}{6} = -\frac{1}{2}$，最大值為 $\sin\frac{\pi}{2} = 1$。
     - 故 $-\frac{1}{2} \le \sin x \le 1$。
  3. 令 $t = \sin x \in [-\frac{1}{2}, 1]$，將原式配方：
     $$y = -(t^2 + 4t) - 2 = -(t + 2)^2 + 2$$
  4. 拋物線開口向下，對稱軸為 $t = -2$。在定義域 $t \in [-\frac{1}{2}, 1]$ 內離對稱軸越遠值越小，故當 $t = 1$ 時有最小值：
     $$y_{\min} = -(1 + 2)^2 + 2 = -9 + 2 = -7$$

### 例題 3
- **題目**：
  1. 畫出函數 $y = \sin x$ 之圖形。
  2. 畫出函數 $y = 3\sin(\frac{x}{2} + \frac{\pi}{2}) + 1$ 之圖形，並求其週期及最大、最小值。
- **答案**：週期為 $4\pi$，最大值為 $4$，最小值為 $-2$
- **圖形描述**：
  - **(1) $y = \sin x$**：標準正弦波，波峰位於 $(\frac{\pi}{2}, 1)$，波谷位於 $(\frac{3\pi}{2}, -1)$，交 $x$ 軸於 $(0,0), (\pi, 0), (2\pi, 0)$，最小正週期為 $2\pi$。
  - **(2) $y = 3\sin(\frac{x}{2} + \frac{\pi}{2}) + 1 = 3\cos\frac{x}{2} + 1$**：在區間 $[-2\pi, 2\pi]$ 內，曲線圍繞中心水平線 $y = 1$ 上下振盪。最高點波峰位於 $(0, 4)$，最低點波谷位於 $(-2\pi, -2)$ 與 $(2\pi, -2)$，交中心線 $y=1$ 於 $x = \pm\pi$ 處。最小正週期為 $4\pi$。
- **解析**：
  1. 將 $y = 3\sin(\frac{x}{2} + \frac{\pi}{2}) + 1$ 變形：
     - 利用 $\sin(\theta + \frac{\pi}{2}) = \cos\theta$，原式可化簡為 $y = 3\cos\frac{x}{2} + 1$。
  2. 求週期與極值：
     - 週期 $T = \frac{2\pi}{1/2} = 4\pi$。
     - 振幅為 $3$，中心線為 $y = 1$。
     - 最大值 $M = 1 + 3 = 4$。
     - 最小值 $m = 1 - 3 = -2$。

#### 類題 3
- **題目**：畫出函數 $y = 2\cos(3x + \pi) + 2$ 圖形，並求週期及最大、最小值。
- **答案**：週期為 $\frac{2\pi}{3}$，最大值為 $4$，最小值為 $0$
- **圖形描述**：曲線圍繞中心水平線 $y = 2$ 振盪，振幅為 $2$。在一個週期 $[0, \frac{2\pi}{3}]$ 內，當 $x = 0$ 時達到最低點 $(0,0)$，當 $x = \frac{\pi}{3}$ 時達到最高點 $(\frac{\pi}{3}, 4)$，當 $x = \frac{2\pi}{3}$ 時回到最低點 $(\frac{2\pi}{3}, 0)$。
- **解析**：
  1. 利用 $\cos(\theta + \pi) = -\cos\theta$，將原式化簡為 $y = -2\cos 3x + 2$。
  2. 週期 $T = \frac{2\pi}{3}$。
  3. 因為 $-1 \le \cos 3x \le 1$，所以 $-2 \le -2\cos 3x \le 2 \Rightarrow 0 \le y \le 4$。
     - 最大值 $M = 4$，最小值 $m = 0$。

### 例題 4
- **題目**：$y = 4\cos(\frac{x}{2} - \frac{\pi}{6})$ 之圖形是由 $y = 4\cos\frac{x}{2}$ 之圖形沿 $x$ 軸正方向平移 $h$ 單位而得，求 $h$ 之最小正值。
- **答案**：$\frac{\pi}{3}$
- **解析**：
  1. 將自變數提出 $x$ 的係數 $\frac{1}{2}$ 進行配方整理：
     $$y = 4\cos\left[\frac{1}{2}\left(x - \frac{\pi}{3}\right)\right]$$
  2. 依據函數圖形平移定理：將 $f(x)$ 沿 $x$ 軸正方向（向右）平移 $h$ 單位，新函數方程式為 $f(x - h)$。
  3. 對比 $y = 4\cos\frac{x}{2}$，可得向右平移量 $h = \frac{\pi}{3}$。

#### 類題 4
- **題目**：$y = \sin 2x$ 之圖形沿 $x$ 軸方向向右最少移動 ____ 單位後與 $y = \sin(2x - \frac{\pi}{2})$ 之圖形重合。
- **答案**：$\frac{\pi}{4}$
- **解析**：
  1. 將目標函數的自變數提取係數 $2$：
     $$y = \sin\left[2\left(x - \frac{\pi}{4}\right)\right]$$
  2. 由此可知，將 $y = \sin 2x$ 向右移動 $\frac{\pi}{4}$ 單位即可重合。

### 例題 5
- **題目**：下列方程式有幾個實根？
  1. $\cos x = \log_2 x$
  2. $3\pi \sin x = x$
  3. $\frac{1}{6}x + \frac{5}{6} = |\cos x| - \cos x$
- **答案**：(1) 1 個 ； (2) 7 個 ； (3) 5 個
- **解析**：
  1. **$\cos x = \log_2 x$**：
     - $y = \cos x$ 的範圍為 $[-1, 1]$。
     - $y = \log_2 x$ 當 $x = 1$ 時 $y = 0$，當 $x = 2$ 時 $y = 1$，當 $x = \frac{1}{2}$ 時 $y = -1$。當 $x > 2$ 時 $y > 1$（超出餘弦函數邊界）。
     - 在 $(0, 2]$ 區間內，$\cos x$ 從 $1$ 遞減至 $\cos 2 < 0$，而 $\log_2 x$ 嚴格遞增，兩圖形恰交於 **1** 點。
  2. **$3\pi \sin x = x \Rightarrow \sin x = \frac{x}{3\pi}$**：
     - 直線 $y = \frac{x}{3\pi}$ 通過原點 $(0,0)$、$(\frac{5\pi}{2}, \frac{5}{6})$ 與端點 $(3\pi, 1)$、$(-3\pi, -1)$。
     - 當 $|x| > 3\pi$ 時，直線 $|y| > 1$，不再與正弦波相交。
     - 畫圖分析交點：
       - 原點 $(0,0)$ 為 1 個交點。
       - 正半軸 $x \in (0, 3\pi)$ 內：在 $(0, \pi)$ 波峰交 2 點，在 $(2\pi, 3\pi)$ 波峰交 1 點？波峰最高點在 $\frac{5\pi}{2}$，直線值為 $\frac{5}{6} < 1$，故直線穿入波峰再穿出，在 $x \in (2\pi, 3\pi)$ 交 2 點？（注意：當 $x = 3\pi$ 時，$\sin 3\pi = 0$，直線為 $1$，故下降段未再相交，交 3 個點？經繪圖計算，正半軸共 3 個交點，負半軸對稱共 3 個交點，加原點共 $1 + 3 + 3 =$ **7** 個解）。
  3. **$\frac{1}{6}x + \frac{5}{6} = |\cos x| - \cos x$**：
     - 令 $g(x) = |\cos x| - \cos x$：當 $\cos x \ge 0$ 時 $g(x) = 0$；當 $\cos x < 0$ 時 $g(x) = -2\cos x \in (0, 2]$。
     - 直線 $L: y = \frac{1}{6}x + \frac{5}{6}$：當 $x = -5$ 時 $y = 0$；當 $x = 7$ 時 $y = 2$。
     - 在 $x \in [-5, 7]$ 範圍內：
       - 直線在 $x = -5$ 處交於 $x$ 軸上的平坦段 $g(x) = 0$（1 個交點）。
       - 在 $(-\frac{3\pi}{2}, -\frac{\pi}{2}) \approx (-4.71, -1.57)$ 波峰區間內，直線穿過拱形波峰，交 2 個點。
       - 在 $(\frac{\pi}{2}, \frac{3\pi}{2}) \approx (1.57, 4.71)$ 波峰區間內，直線穿過拱形波峰，交 2 個點。
     - 總計交點數為 $1 + 2 + 2 =$ **5** 個。

#### 類題 5
- **題目**：$x = 10\sin x$ 之實數解有 ____ 個。
- **答案**：7
- **解析**：
  1. 將方程式改寫為 $\sin x = \frac{x}{10}$，求 $y = \sin x$ 與直線 $y = \frac{x}{10}$ 的交點個數。
  2. 直線端點為 $(10, 1)$ 與 $(-10, -1)$。由於 $10 \approx 3.18\pi$，考量 $x \in [-3.18\pi, 3.18\pi]$：
     - 原點 $(0,0)$ 為 1 個解。
     - 右半軸 $x > 0$：在 $(0, \pi)$ 區間波峰交 2 個點；在 $(2\pi, 3\pi)$ 區間波峰（頂點 $x = 2.5\pi \approx 7.85$，直線值 $0.785 < 1$）交 1 點（因為當 $x \to 3.18\pi$ 時直線升至 $1$）。正半軸共 3 個交點。
     - 左半軸 $x < 0$：由奇函數對稱性，負半軸亦有 3 個交點。
  3. 實數解總數為 $1 + 3 + 3 =$ **7** 個。

### 例題 6
- **題目**：作 $y = \frac{1}{2}(\sin x + \cos x) + \frac{1}{2}|\sin x - \cos x|$ 之圖形，並求其週期。
- **答案**：週期為 $2\pi$
- **圖形描述**：圖形為 $\sin x$ 與 $\cos x$ 兩函數的「上包絡線」（即在每個 $x$ 處取兩者較大值）。在 $[\frac{\pi}{4}, \frac{5\pi}{4}]$ 取 $\sin x$ 的波峰部分，在 $[\frac{5\pi}{4}, \frac{9\pi}{4}]$ 取 $\cos x$ 的波峰部分，兩曲線在交點處滑順連貫，形成週期為 $2\pi$ 的連續波浪形圖形。
- **解析**：
  1. 分段討論絕對值：
     - 當 $\sin x \ge \cos x$ 時，$y = \frac{1}{2}(\sin x + \cos x) + \frac{1}{2}(\sin x - \cos x) = \sin x$。
     - 當 $\sin x < \cos x$ 時，$y = \frac{1}{2}(\sin x + \cos x) - \frac{1}{2}(\sin x - \cos x) = \cos x$。
  2. 綜上，$y = \max(\sin x, \cos x)$。
  3. 因為 $\sin x$ 與 $\cos x$ 的最小公倍週期為 $2\pi$，且取最大值操作未改變整體重複間隔，故最小正週期為 **$2\pi$**。

#### 類題 6
- **題目**：畫出函數 $f(x) = (\sin x - \cos x) + |\sin x + \cos x|$ 之圖形並求其週期。
- **答案**：週期為 $2\pi$
- **解析**：
  1. 分段討論：
     - 當 $\sin x + \cos x \ge 0$ 時，$f(x) = 2\sin x$。
     - 當 $\sin x + \cos x < 0$ 時，$f(x) = -2\cos x$。
  2. 函數在轉折點處相連，且分段條件 $\sin x + \cos x \ge 0$ 的週期為 $2\pi$，故整體最小正週期為 **$2\pi$**。

### 例題 7
- **題目**：求下列函數之週期：
  1. $\cos |x|$
  2. $|\tan 2x|$
  3. $\sin(\frac{\pi}{3}x + 3)$
  4. $|2\sin 3x|$
  5. $|\sin x| + |\cos x|$
- **答案**：(1) $2\pi$ ； (2) $\frac{\pi}{2}$ ； (3) $6$ ； (4) $\frac{\pi}{3}$ ； (5) $\frac{\pi}{2}$
- **解析**：
  1. $\cos |x| = \cos x$（餘弦為偶函數），週期為 **$2\pi$**。
  2. $\tan 2x$ 週期為 $\frac{\pi}{2}$，取絕對值後翻折不改變正切函數的最小正週期，故為 **$\frac{\pi}{2}$**。
  3. $x$ 的係數為 $\frac{\pi}{3}$，週期 $T = \frac{2\pi}{\pi/3} = \mathbf{6}$。
  4. $\sin 3x$ 週期為 $\frac{2\pi}{3}$，取絕對值 $|2\sin 3x|$ 後，負半波翻折為正半波，週期減半為 **$\frac{\pi}{3}$**。
  5. $f(x + \frac{\pi}{2}) = |\sin(x + \frac{\pi}{2})| + |\cos(x + \frac{\pi}{2})| = |\cos x| + |-\sin x| = f(x)$，故最小正週期為 **$\frac{\pi}{2}$**。

#### 類題 7
- **題目**：求下列函數之週期：
  1. $y = \sin 3x$
  2. $y = \sec 2x$
  3. $y = |\sin x| + \cos x$
  4. $y = |\sin 3x| + |\cos 3x|$
- **答案**：(1) $\frac{2\pi}{3}$ ； (2) $\pi$ ； (3) $2\pi$ ； (4) $\frac{\pi}{6}$
- **解析**：
  1. $y = \sin 3x \Rightarrow T = \frac{2\pi}{3}$。
  2. $y = \sec 2x \Rightarrow T = \frac{2\pi}{2} = \pi$。
  3. $|\sin x|$ 週期為 $\pi$，$\cos x$ 週期為 $2\pi$。兩者相加，最小公倍週期為 **$2\pi$**（代入 $x+\pi$ 可驗證 $f(x+\pi) \neq f(x)$）。
  4. 利用例題 7(5) 結論，將自變數 $x$ 縮小為 3 倍，週期 $T = \frac{\pi/2}{3} = \frac{\pi}{6}$。

## 習題 A 部分

### 1. 題目
$x = 10\sin x + 10|\sin x|$ 在 $x \in [-2\pi, 2\pi]$ 中的實數解有 ____ 個。
- **答案**：2
- **解析**：
  1. 當 $\sin x \ge 0$ 時，$10\sin x + 10\sin x = 20\sin x \Rightarrow x = 20\sin x \Rightarrow \sin x = \frac{x}{20}$。
  2. 當 $\sin x < 0$ 時，$10\sin x - 10\sin x = 0 \Rightarrow x = 0$（但 $x = 0$ 時 $\sin 0 = 0 \ge 0$，為邊界界限）。
  3. 檢驗 $\sin x \ge 0$ 的區間（即 $x \in [-2\pi, -\pi] \cup [0, \pi]$）：
     - 在 $[0, \pi]$ 內：$x = 0$ 為 1 個解。在 $(0, \pi)$ 內，正弦波峰值 $1 > \frac{\pi/2}{20} \approx 0.0785$，直線 $y = \frac{x}{20}$ 穿過波峰，交於 1 個解。
     - 在 $[-2\pi, -\pi]$ 內：$x < 0$ 故 $\frac{x}{20} < 0$，但此區間 $\sin x \ge 0$，無解。
  4. 實數解共 **2** 個。

### 2. 題目
$y = \sin 2x$ 與 $y = \frac{1}{2}$ 兩者圖形在 $0 \le x \le 10$ 之區間內共有幾個交點？
- **答案**：7
- **解析**：
  1. 令 $\theta = 2x$，當 $x \in [0, 10]$ 時，$\theta \in [0, 20]$。
  2. 求 $\sin\theta = \frac{1}{2}$ 在 $\theta \in [0, 20]$ 內的解個數。
  3. 基本解為 $\theta = \frac{\pi}{6} + 2k\pi$ 或 $\frac{5\pi}{6} + 2k\pi$ （$k \in \mathbb{Z}$）：
     - $k = 0$: $\frac{\pi}{6} \approx 0.52$, $\frac{5\pi}{6} \approx 2.62$ （2 個）

     - 中心線 $d = \frac{1 + (-3)}{2} = \mathbf{-1}$。
