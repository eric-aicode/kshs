CHAPTER 01

和差角與倍角公式：結構對稱性與幾何推導

💡 正弦與餘弦的和差角口訣與結構特徵

許多同學在背和差角時容易正負號混淆。記住這兩大口訣與對稱性：

🌟 和差角記憶法寶

正弦（Sin）友善包容：異性相吸，符號相同 $$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$ 餘弦（Cos）自私排他：同性相聚，符號相反 $$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$

✨ 圖 1：單位圓距離公式推導餘弦差角公式 —— 幾何弦長平方展開直接給出 $\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$

⚡ 二倍角與降次公式的「雙向互通」

二倍角公式中，餘弦二倍角有三種等價寫法： $$\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$$ 移項即為大考計算極值的最強利器——降次公式（Degree Reduction）： $$\Large \cos^2\theta = \frac{1 + \cos 2\theta}{2}, \quad \sin^2\theta = \frac{1 - \cos 2\theta}{2}$$ 凡是遇到 $\sin^2\theta$ 或 $\cos^2\theta$ 的題目，立刻降次化為 $2\theta$ 的一次式，即可銜接正餘弦疊合！

CHAPTER 02

三角函數圖形本質：四大參數 $A, b, c, d$ 變換奧祕

🌊 $y = A\sin(bx + c) + d$ 的四大角色解構

參數 幾何影響 公式與計算規則 段考高頻易錯地雷
$A$ 鉛直伸縮（振幅） 振幅為 $|A|$，波峰與波谷距離為 $2|A|$ $A$ 若為負數，圖形會上下翻轉，但振幅永遠是正值 $|A|$！
$b$ 水平伸縮（週期） 週期 $T = \frac{2\pi}{|b|}$ 若 $b$ 變為 2 倍，圖形水平壓縮為 $\frac{1}{2}$，週期減半！
$c$ 水平平移（相位） 向左/向右平移 $\frac{|c|}{|b|}$ 單位 必考第一死穴！平移量是看 $x$ 前面的係數！必須改寫為 $A\sin[b(x - h)]$，平移量是 $h = -\frac{c}{b}$，絕不是 $c$！
$d$ 鉛直平移（中軸線） 中軸線 $y = d$；最大值 $d + |A|$，最小值 $d - |A|$ 中軸線即為上落極值的平均值：$d = \frac{M + m}{2}$。

CHAPTER 03

實根個數判定：超越方程與代數直線交點四大準則

🔍 「交點個數即實根個數」的作圖破解 SOP

當題目出現 $\cos x = \log_2 x$ 或 $x = 10\sin x$ 等「代數式與三角函數混合」的超越方程時，代數方法無法直接解出 $x$。唯一秒殺手段是拆成兩個圖形數交點！

🎯 作圖數根 4 大檢驗步驟

1. 鎖定三角函數值域邊界：$y = \sin x \in [-1, 1]$，直線或對數函數一旦超出 $[-1, 1]$ 就絕對不可能有交點！ 2. 計算臨界邊界點：例如直線 $y = \frac{x}{10}$，當 $y = 1$ 時 $x = 10$。因為 $\pi \approx 3.14$，$10 \approx 3.18\pi$，這代表直線在 $3\pi$ 之後才會衝出上限！ 3. 波段逐一清點： - 在 $[0, \pi]$ 正弦為正波，交 2 點。 - 在 $[2\pi, 3\pi]$ 正弦又為正波，因 $3\pi \approx 9.42 < 10$，波峰在 $2.5\pi \approx 7.85$，交 1 點。 - 正半軸共 $2 + 1 = 3$ 點。 4. 利用對稱性與原點：奇函數對稱於原點，負半軸亦有 3 點；加上原點 $(0, 0)$，總計 $3 + 3 + 1 = 7$ 點！

CHAPTER 04

正餘弦疊合定理：輔助角直角三角形與極值基礎

📐 正餘弦疊合的核心幾何本質

任何同角頻率的線性組合 $a\sin x + b\cos x$ 都可以視為以 $(a, b)$ 為股長的直角三角形： $$a\sin x + b\cos x = \sqrt{a^2 + b^2} \left(\frac{a}{\sqrt{a^2 + b^2}}\sin x + \frac{b}{\sqrt{a^2 + b^2}}\cos x\right)$$ 令 $\cos\phi = \frac{a}{\sqrt{a^2+b^2}}$，$\sin\phi = \frac{b}{\sqrt{a^2+b^2}}$，則由正弦和角公式得： $$\Large a\sin x + b\cos x = \sqrt{a^2 + b^2}\sin(x + \phi)$$

CHAPTER 05

受限區間極值求解：端點值 vs 波峰波谷判定法

⚠️ 為什麼不能直接寫最大值是 $\sqrt{a^2+b^2}$？

當題目給定 $x \in [\alpha, \beta]$ 時，合成後的角 $\theta = x + \phi$ 的範圍為 $[\alpha + \phi, \beta + \phi]$。 只有當此區間包含 $\frac{\pi}{2} + 2k\pi$ 時，正弦值才能取到最高點 $1$！

💣 段考經典例題：$-\frac{\pi}{6} \le x \le \frac{5\pi}{6}$ 求 $y = \sqrt{3}\cos x + \sin x$ 極值

1. 疊合：$y = 2\left(\frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x\right) = 2\sin(x + \frac{\pi}{3})$。 2. 確定範圍：令 $\theta = x + \frac{\pi}{3}$。 因為 $-\frac{\pi}{6} \le x \le \frac{5\pi}{6}$，所以 $\frac{\pi}{6} \le \theta \le \frac{7\pi}{6}$。 3. 檢驗極值點： - $\frac{\pi}{2} \in [\frac{\pi}{6}, \frac{7\pi}{6}]$，所以最大值出現在 $\theta = \frac{\pi}{2} \implies x = \frac{\pi}{6}$，最大值 $M = 2(1) = 2$。 - 最低點 $\frac{3\pi}{2} \approx 1.5\pi$ **不在區間內**！故最小值必須由端點決定： $\theta = \frac{\pi}{6} \implies \sin\frac{\pi}{6} = \frac{1}{2}$； $\theta = \frac{7\pi}{6} \implies \sin\frac{7\pi}{6} = -\frac{1}{2}$。 因此最小值出現在 $\theta = \frac{7\pi}{6} \implies x = \frac{5\pi}{6}$，最小值 $m = 2(-\frac{1}{2}) = -1$！ 4. 數對 $(a, b, M, m) = (\frac{\pi}{6}, \frac{5\pi}{6}, 2, -1)$。

CHAPTER 06

二次齊次式與對稱換元法：$t = \sin x \pm \cos x$

🔄 對稱換元法的降維心法

當題目同時出現 $(\sin x + \cos x)$ 與乘積 $(\sin x\cos x)$ 時： $$\text{令 } t = \sin x + \cos x = \sqrt{2}\sin(x + \frac{\pi}{4})$$ 關鍵鐵律：$t$ 的範圍被緊緊鎖死在 $[-\sqrt{2}, \sqrt{2}]$！ 兩邊平方得： $$t^2 = 1 + 2\sin x\cos x \implies \sin x\cos x = \frac{t^2 - 1}{2}$$ 原式立刻轉化為關於 $t$ 的一元二次函數，再用國中配方法即可秒殺極值！

CHAPTER 07

圓參數式幾何應用：內接長方形與幾何極限

⭕ 圓上的動點坐標參數化

圓 $(x - h)^2 + (y - k)^2 = R^2$ 上的任意點皆可設為： $$\begin{cases} x = h + R\cos\theta \\ y = k + R\sin\theta \end{cases}$$ 求線性目標式 $Ax + By + C$ 的極值時，代入直接化為正餘弦疊合： $$A(h + R\cos\theta) + B(k + R\sin\theta) + C = R(A\cos\theta + B\sin\theta) + (Ah + Bk + C)$$ 最大值為 $(Ah + Bk + C) + R\sqrt{A^2 + B^2}$，幾何上即為點到直線距離的極值！
