和差角核心定理

一、 正弦、餘弦與正切之和差角公式

三角函數之基本運算基石，注意餘弦符號之正負變號口訣：

1. 正弦和角 $\sin(\alpha + \beta)=$
$$\sin\alpha\cos\beta + \cos\alpha\sin\beta$$
2. 正弦差角 $\sin(\alpha - \beta)=$
$$\sin\alpha\cos\beta - \cos\alpha\sin\beta$$
3. 餘弦和角 $\cos(\alpha + \beta)=$
$$\cos\alpha\cos\beta - \sin\alpha\sin\beta \quad (\text{注意減號！})$$
4. 餘弦差角 $\cos(\alpha - \beta)=$
$$\cos\alpha\cos\beta + \sin\alpha\sin\beta \quad (\text{注意加號！})$$
5. 正切和角 $\tan(\alpha + \beta)=$
$$\frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$
6. 正切差角 $\tan(\alpha - \beta)=$
$$\frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$$
重要導出公式

二、 二倍角公式與半角公式

正弦二倍角 必背
$\sin 2\theta=$
$$2\sin\theta\cos\theta$$
餘弦二倍角（三種形式） 降次神器
$\cos 2\theta=$
$$\cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$$
正切二倍角 和角特例
$\tan 2\theta=$
$$\frac{2\tan\theta}{1 - \tan^2\theta}$$
半角公式（降次換角） 開根號注意正負
$\sin^2\frac{\theta}{2}=, \cos^2\frac{\theta}{2}=$
$$\sin^2\frac{\theta}{2} = \frac{1 - \cos\theta}{2}, \quad \cos^2\frac{\theta}{2} = \frac{1 + \cos\theta}{2}$$
圖形本質與對照

一、 三大基本三角函數圖形性質比較表

函數 定義域 值域 (振幅) 基本週期 奇偶性與對稱特徵
$y = \sin x$ $\mathbb{R}$ $[-1, 1]$ (振幅 1) $2\pi$ 奇函數：$\sin(-x) = -\sin x$（對稱於原點 $(0,0)$）
$y = \cos x$ $\mathbb{R}$ $[-1, 1]$ (振幅 1) $2\pi$ 偶函數：$\cos(-x) = \cos x$（對稱於 $y$ 軸）
$y = \tan x$ $x \neq k\pi + \frac{\pi}{2}, k \in \mathbb{Z}$ $\mathbb{R}$ (無最大最小值) $\pi$ (只有正餘弦一半) 奇函數：$\tan(-x) = -\tan x$（漸近線 $x = k\pi + \frac{\pi}{2}$）
平移與伸縮變換

二、 綜合變換標準型 $y = A\sin(bx + c) + d$ 之四大特徵

將其改寫為標準形態 $y = A\sin\left[b\left(x + \frac{c}{b}\right)\right] + d$：

1. 函數振幅 (Amplitude) =
$$|A| = \frac{\text{最大值} - \text{最小值}}{2}$$
2. 函數週期 (Period) $T=$
$$\frac{2\pi}{|b|} \quad (\tan \text{ 函數則為 } \frac{\pi}{|b|})$$
3. 基準中心線 (Midline) 與極值 =
$$y = d = \frac{\max + \min}{2}, \quad \text{範圍: } [d - |A|, d + |A|]$$
4. 水平左右平移量 =
$$\text{向右平移 } -\frac{c}{b} \text{ 單位（即向左平移 } \frac{c}{b} \text{ 單位）}$$
高頻題型

三、 三角函數二次式配方求極值法

🔑 經典標準步驟：

1. **統一函數名稱**：利用 $\sin^2 x + \cos^2 x = 1 \implies \cos^2 x = 1 - \sin^2 x$ 將式子化為純 $\sin$ 或純 $\cos$ 的二次函數。
2. **變數代換**：令 $t = \sin x$ 或 $t = \cos x$。
3. **嚴格確定 $t$ 的範圍**：若 $x \in \mathbb{R}$，則 $-1 \le t \le 1$；若題目給定角度範圍（如 $\frac{\pi}{6} \le x \le \frac{5\pi}{6}$），需先找出 $\sin x$ 的最大與最小值！
4. **配方法求拋物線頂點**：注意頂點是否落在 $t$ 的受限區間內！若在區間外，極值發生在區間端點處！

大考必考核心

一、 正餘弦線性組合疊合定理

同頻率的正弦與餘弦線性組合 $a\sin x + b\cos x$，可合成為單一振幅的正弦波或餘弦波：

1. 合成正弦型 $a\sin x + b\cos x=$
$$\sqrt{a^2 + b^2} \sin(x + \theta) \quad \left(\cos\theta = \frac{a}{\sqrt{a^2+b^2}}, \sin\theta = \frac{b}{\sqrt{a^2+b^2}}\right)$$
2. 合成餘弦型 $a\sin x + b\cos x=$
$$\sqrt{a^2 + b^2} \cos(x - \phi) \quad \left(\cos\phi = \frac{b}{\sqrt{a^2+b^2}}, \sin\phi = \frac{a}{\sqrt{a^2+b^2}}\right)$$
3. $x \in \mathbb{R}$ 時之極值範圍:
$$-\sqrt{a^2 + b^2} \le a\sin x + b\cos x \le \sqrt{a^2 + b^2}$$
4. 達最大值時之 $\tan x$ 條件:
$$\tan x = \frac{a}{b} \quad (\text{因為 } x + \theta = \frac{\pi}{2} \implies \tan x = \cot\theta = \frac{\cos\theta}{\sin\theta} = \frac{a}{b})$$
幾何綜合題必備

二、 圓參數式與幾何極值轉化

圓之標準參數式 解析幾何
圓 $(x-h)^2 + (y-k)^2 = r^2$ 上任一點 $P(x,y)$:
$$\begin{cases} x = h + r\cos\theta \\ y = k + r\sin\theta \end{cases} \quad (\theta \in [0, 2\pi))$$
一次式 $Ax + By + C$ 極值 化為疊合
代入參數式後得:
$$r(A\cos\theta + B\sin\theta) + (Ah + Bk + C) \implies \text{最大值 } = (Ah+Bk+C) + r\sqrt{A^2+B^2}$$
