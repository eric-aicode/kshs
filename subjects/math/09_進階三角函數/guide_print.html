§9-1 和差角公式、倍半角公式、§9-2 正弦/餘弦/正切三大圖形性質對照矩陣

第 1 頁 / 共 2 頁
一、 正弦、餘弦與正切之和差角公式 必背核心
【正弦和差角公式】
$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$
• 同號口訣：sin 和角為「正餘 + 餘正」，差角為「正餘 - 餘正」。
【餘弦和差角公式】（注意變號！）
$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$
• 異號口訣：cos 和角為「餘餘 - 正正」，差角為「餘餘 + 正正」。
【正切和角公式】
$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$
【正切差角公式】
$\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$
二、 二倍角公式與降次半角公式 化簡降次
正弦二倍角 $\sin 2\theta = 2\sin\theta\cos\theta$
餘弦二倍角 (三型) $\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$
正切二倍角 $\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta}$
降次半角公式 $\sin^2\frac{\theta}{2} = \frac{1 - \cos\theta}{2}, \quad \cos^2\frac{\theta}{2} = \frac{1 + \cos\theta}{2}, \quad \tan^2\frac{\theta}{2} = \frac{1 - \cos\theta}{1 + \cos\theta}$
三、 §9-2 基本三角函數圖形性質對照表 圖形本質
函數 定義域 值域 (振幅) 基本週期 對稱性與奇偶性
$y = \sin x$ $\mathbb{R}$ $[-1, 1]$ (振幅 1) $2\pi$ 奇函數，對稱於原點 $(0,0)$
$y = \cos x$ $\mathbb{R}$ $[-1, 1]$ (振幅 1) $2\pi$ 偶函數，對稱於 $y$ 軸
$y = \tan x$ $x \neq k\pi + \frac{\pi}{2}, k \in \mathbb{Z}$ $\mathbb{R}$ (無振幅) $\pi$ 奇函數，漸近線 $x = k\pi + \frac{\pi}{2}$

函數變換標準式、二次換元求極值、§9-3 正餘弦疊合定理、圓參數式與幾何極值應用

第 2 頁 / 共 2 頁
四、 圖形伸縮平移標準型 $y = A\sin(bx + c) + d$ 變換法則
【四大核心參數意義】
• 振幅 (Amplitude)：$|A| = \frac{\max - \min}{2}$
• 週期 (Period)：$T = \frac{2\pi}{|b|}$ （$\tan$ 為 $\frac{\pi}{|b|}$）
• 中軸基準線：$y = d = \frac{\max + \min}{2}$
• 函數範圍：$[d - |A|, d + |A|]$
【水平與鉛直平移口訣】
將式子提出 $b$：$y = A\sin\left[b\left(x + \frac{c}{b}\right)\right] + d$
• 左右平移：左加右減，向右平移 $-\frac{c}{b}$ 單位。
• 上下平移：上加下減，向上平移 $d$ 單位。
五、 三角函數二次式配方求極值技巧 換元受限
• 化同名：利用 $\cos^2 x = 1 - \sin^2 x$ 化為純單一函數之二次式。
• 設元與界定範圍：令 $t = \sin x$ 或 $t = \cos x$。務必先定出 $t$ 的受限區間！
★ 警惕：若角度受限（如 $\frac{\pi}{6} \le x \le \frac{5\pi}{6}$），則 $t \in [\frac{1}{2}, 1]$，配方求得頂點後需檢驗頂點是否在區間內，若在區間外則極值必在端點！
六、 §9-3 正餘弦疊合定理與極值條件 ★ 大考核心
1. 合成正弦型
$$a\sin x + b\cos x = \sqrt{a^2 + b^2}\sin(x + \theta)$$
其中 $\cos\theta = \frac{a}{\sqrt{a^2+b^2}}$，$\sin\theta = \frac{b}{\sqrt{a^2+b^2}}$。
2. 合成餘弦型
$$a\sin x + b\cos x = \sqrt{a^2 + b^2}\cos(x - \phi)$$
其中 $\cos\phi = \frac{b}{\sqrt{a^2+b^2}}$，$\sin\phi = \frac{a}{\sqrt{a^2+b^2}}$。
無限制時之極值 $-\sqrt{a^2 + b^2} \le a\sin x + b\cos x \le \sqrt{a^2 + b^2}$
最大值之角度條件 當 $x + \theta = \frac{\pi}{2} \implies \tan x = \cot\theta = \frac{a}{b}$ 時取最大值。
七、 圓參數式幾何應用 綜合題型
圓之標準參數式
點 $P(x,y)$ 在圓 $(x-h)^2 + (y-k)^2 = r^2$ 上：
$\begin{cases} x = h + r\cos\theta \\ y = k + r\sin\theta \end{cases} \quad (\theta \in [0, 2\pi))$
線性表達式 $Ax + By + C$ 極值
代入參數式轉為三角疊合：
$r(A\cos\theta + B\sin\theta) + (Ah + Bk + C)$
$\implies \text{最大值} = (Ah+Bk+C) + r\sqrt{A^2+B^2}$
