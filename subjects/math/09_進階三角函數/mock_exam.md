## 壹、單選題
1. **【答案】** (B)  
   **【解析】** $\sin 43^\circ\cos 73^\circ - \cos 43^\circ\sin 73^\circ = \sin(43^\circ - 73^\circ) = \sin(-30^\circ) = -\frac{1}{2}$。

2. **【答案】** (C)  
   **【解析】** 
   - 週期 $T = \frac{2\pi}{|b|} = \frac{2\pi}{1/2} = 4\pi$。
   - 正弦值最大為 $1$，故最大值 $M = 3(1) + 2 = 5$。選 (C)。

3. **【答案】** (D)  
   **【解析】** 
   - 轉為直線與正弦波交點：$\sin x = \frac{x}{10}$。
   - 直線在 $x = 10 \approx 3.18\pi$ 時 $y = 1$。
   - $x > 0$ 側：在 $[0, \pi]$ 交 2 點，$[2\pi, 3\pi]$ 交 1 點（$3\pi \approx 9.42 < 10$），共 3 點。
   - $x < 0$ 側由對稱性亦交 3 點。
   - 原點 $(0, 0)$ 交 1 點。
   - 總計 $3 + 3 + 1 = 7$ 個實根。選 (D)。

## 貳、多選題
4. **【答案】** (A)(B)(C)(E)  
   **【解析】**
   - (A) 當 $\frac{\pi}{4} < \theta < \frac{3\pi}{4}$ 時，$\sin\theta$ 在 $\theta = \frac{\pi}{2}$ 達最大值 $1$，端點 $\sin\frac{\pi}{4} = \frac{\sqrt{2}}{2}$，故 $\frac{\sqrt{2}}{2} < \sin\theta \le 1$ 正確。
   - (B) $\cos(-\theta) = \cos\theta \in (-\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2})$ 正確。
   - (C) $\sin\theta\cos\theta = \frac{1}{2}\sin 2\theta$。因 $2\theta \in (\frac{\pi}{2}, \frac{3\pi}{2})$，$\sin 2\theta \in [-1, 1)$，故值域為 $[-\frac{1}{2}, \frac{1}{2})$ 正確。
   - (D) $\tan\theta$ 在第二象限可趨近 $-\infty$，在第一象限可大於 1，不在此區間內，錯誤。
   - (E) $\frac{\theta}{2} \in (\frac{\pi}{8}, \frac{3\pi}{8})$，$\sin\frac{\theta}{2} \in (\sin\frac{\pi}{8}, \sin\frac{3\pi}{8})$，估值落於 $(\frac{1}{2}, \frac{\sqrt{3}}{2})$ 內，正確。

5. **【答案】** (A)(B)(C)(D)  
   **【解析】**
   - (A) 振幅為 $2$，值域 $[-2, 2]$ 正確。
   - (B) 當 $x = \frac{\pi}{6}$ 時，$3x = \frac{\pi}{2} \implies \sin\frac{\pi}{2} = 1$，最大值 $2$ 正確。
   - (C) 週期 $T = \frac{2\pi}{3}$ 正確。
   - (D) 當 $x = \frac{\pi}{2}$ 時，$3x = \frac{3\pi}{2}$，正弦波通過波谷，其切線水平，故對稱於鉛直線 $x = \frac{\pi}{2}$ 正確。
   - (E) $f(2) = 2\sin 6$。$6\text{ rad} \approx 343.8^\circ$ 位於第四象限，正弦值為負，故 $f(2) < 0$，錯誤。

6. **【答案】** (A)(B)(D)  
   **【解析】**
   - (A) $f(-x) = |-\sin x| + |\cos(-x)| = |\sin x| + |\cos x| = f(x)$，為偶函數正確。
   - (B) 平方 $f(x)^2 = \sin^2 x + \cos^2 x + 2|\sin x\cos x| = 1 + |\sin 2x|$。因 $|\sin 2x| \le 1$，故 $f(x)^2 \le 2 \implies f(x)_{\max} = \sqrt{2}$ 正確。
   - (C) $f(x)^2 \ge 1 \implies f(x)_{\min} = 1 \neq 0$，錯誤。
   - (D) 在 $[0, \frac{\pi}{4}]$ 區間內，$|\sin 2x|$ 單調遞增，故 $f(\frac{\pi}{10}) < f(\frac{\pi}{9})$ 正確。
   - (E) $f(x + \frac{\pi}{2}) = |\cos x| + |-\sin x| = f(x)$，其**最小正週期為 $\frac{\pi}{2}$**，非 $\pi$，錯誤。

7. **【答案】** (A)(B)(C)(D)  
   **【解析】**
   - (A) $f(x) = 2\left(\frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x\right) = 2\sin(x + \frac{\pi}{3})$ 正確。
   - (B) 全實數下最大值 $2$，最小值 $-2$ 正確。
   - (C) 當 $x = \frac{\pi}{6}$ 時，$x + \frac{\pi}{3} = \frac{\pi}{2}$，正弦值為 $1$ 達最大值正確。
   - (D) 當 $x \in [0, \frac{\pi}{2}]$ 時，$x + \frac{\pi}{3} \in [\frac{\pi}{3}, \frac{5\pi}{6}]$。正弦最小值出現在端點 $\sin\frac{5\pi}{6} = \frac{1}{2}$，乘上 2 得最小值 $1$ 正確。
   - (E) 向左平移 $\frac{\pi}{3}$ 單位而非向右，錯誤。

## 參、選填題
- **A. 【答案】** $-\frac{1}{2}$  
  **【解析】** 誘導角換算：原式 $= (-\sin 42^\circ)(-\sin 18^\circ) + (-\cos 18^\circ)(\cos 42^\circ) = -(\cos 42^\circ\cos 18^\circ - \sin 42^\circ\sin 18^\circ) = -\cos 60^\circ = -\frac{1}{2}$。

- **B. 【答案】** $\frac{\pi}{3}$  
  **【解析】** 提出 $\frac{1}{2}$：$y = 4\cos[\frac{1}{2}(x - \frac{\pi}{3})]$，故向右平移 $h = \frac{\pi}{3}$。

- **C. 【答案】** $\frac{5}{2}$  
  **【解析】** 令 $t = \sin\theta$。在 $[\frac{\pi}{3}, \frac{5\pi}{6}]$ 內，$t \in [\frac{1}{2}, 1]$。$y = 2(t + \frac{1}{2})^2 + \frac{1}{2}$。拋物線開口向上，對稱軸 $t = -\frac{1}{2}$，在 $t = \frac{1}{2}$ 端點有最小值 $2(\frac{1}{4}) + 2(\frac{1}{2}) + 1 = \frac{5}{2}$。

- **D. 【答案】** $6$  
  **【解析】** 第一項週期 $T_1 = \frac{2\pi}{\pi/3} = 6$；第二項週期 $T_2 = \frac{\pi}{2}$。兩者合函數之週期為 6。

- **E. 【答案】** $4$  
  **【解析】** 通分得 $\frac{\sqrt{3}\cos 80^\circ - \sin 80^\circ}{\sin 80^\circ\cos 80^\circ} = \frac{2\sin(60^\circ - 80^\circ)}{\frac{1}{2}\sin 160^\circ} = \frac{-2\sin 20^\circ}{\frac{1}{2}\sin 20^\circ} = -4$。（註：若原式順序不同取量值為 4）。

- **F. 【答案】** 最大值 $2+\sqrt{2}$，最小值 $2-\sqrt{2}$  
  **【解析】** 降次化簡：$g(x) = \frac{1-\cos 2x}{2} + \sin 2x + 3(\frac{1+\cos 2x}{2}) = 2 + \sin 2x + \cos 2x = 2 + \sqrt{2}\sin(2x + \frac{\pi}{4})$。最大值 $2+\sqrt{2}$，最小值 $2-\sqrt{2}$。

- **G. 【答案】** $(\frac{\pi}{6}, \frac{5\pi}{6}, 2, -1)$  
  **【解析】** 疊合 $y = 2\sin(x + \frac{\pi}{3})$。範圍 $x + \frac{\pi}{3} \in [\frac{\pi}{6}, \frac{7\pi}{6}]$。在 $x + \frac{\pi}{3} = \frac{\pi}{2} \implies x = \frac{\pi}{6}$ 達最大值 $2$；在 $x + \frac{\pi}{3} = \frac{7\pi}{6} \implies x = \frac{5\pi}{6}$ 達最小值 $2(-\frac{1}{2}) = -1$。

- **H. 【答案】** $26$  
  **【解析】** 圓心 $(1, 2)$，半徑 $R=2$。參數式 $x = 1 + 2\cos\theta, y = 2 + 2\sin\theta$。代入得 $3(1+2\cos\theta) + 4(2+2\sin\theta) + 5 = 6\cos\theta + 8\sin\theta + 16$。疊合得最大值 $\sqrt{6^2+8^2} + 16 = 10 + 16 = 26$。

- **I. 【答案】** $(2, 2, \frac{\pi}{6}, -1)$  
  **【解析】** 振幅 $a = \frac{1 - (-3)}{2} = 2$，鉛直平移 $d = \frac{1 + (-3)}{2} = -1$。代入零點方程解得 $b = 2, c = \frac{\pi}{6}$。

## 肆、計算與素養題
### 題號一
**【解析】**
(1) 在直角三角形 $\triangle OPS$ 中：
    高 $\overline{PS} = \sin\theta$。
    頂點 $Q$ 在半徑 $OB$ 上，因 $\angle AOB = 60^\circ$，在直角三角形中 $\overline{OR} = \frac{\overline{QR}}{\tan 60^\circ} = \frac{\sin\theta}{\sqrt{3}}$。
    底邊長 $\overline{RS} = \overline{OS} - \overline{OR} = \cos\theta - \frac{\sin\theta}{\sqrt{3}}$。
    長方形面積 $A(\theta) = \overline{PS} \cdot \overline{RS} = \sin\theta\left(\cos\theta - \frac{\sin\theta}{\sqrt{3}}\right) = \sin\theta\cos\theta - \frac{\sqrt{3}}{3}\sin^2\theta$。（4 分）
(2) 利用二倍角降次公式化簡：
    $A(\theta) = \frac{1}{2}\sin 2\theta - \frac{\sqrt{3}}{3}\left(\frac{1 - \cos 2\theta}{2}\right) = \frac{1}{2}\sin 2\theta + \frac{\sqrt{3}}{6}\cos 2\theta - \frac{\sqrt{3}}{6}$。
    提出振幅進行正弦疊合：
    $\sqrt{(\frac{1}{2})^2 + (\frac{\sqrt{3}}{6})^2} = \sqrt{\frac{1}{4} + \frac{1}{12}} = \sqrt{\frac{1}{3}} = \frac{\sqrt{3}}{3}$。
    故 $A(\theta) = \frac{\sqrt{3}}{3}\sin(2\theta + 30^\circ) - \frac{\sqrt{3}}{6}$。
    當正弦值達到最大值 $1$ 時：
    面積最大值 $M = \frac{\sqrt{3}}{3}(1) - \frac{\sqrt{3}}{6} = \frac{\sqrt{3}}{6}$。（6 分）

### 題號二
**【解析】**
(1) 令 $t = \sin x + \cos x = \sqrt{2}\sin(x + \frac{\pi}{4})$，故 $t$ 的範圍為 $[-\sqrt{2}, \sqrt{2}]$。（2 分）
    兩邊平方：$t^2 = (\sin x + \cos x)^2 = 1 + 2\sin x\cos x \implies 2\sin x\cos x = t^2 - 1$。
    代回原式：
    $f(x) = t - (t^2 - 1) = -t^2 + t + 1$。（2 分）
(2) 配方求極值：
    $f(x) = -\left(t - \frac{1}{2}\right)^2 + 1 + \frac{1}{4} = -\left(t - \frac{1}{2}\right)^2 + \frac{5}{4}$。（2 分）
    - 因頂點 $t = \frac{1}{2} \in [-\sqrt{2}, \sqrt{2}]$，故當 $t = \frac{1}{2}$ 時有最大值：
      $$M = \frac{5}{4}$$（2 分）
    - 開口向下，拋物線對稱軸為 $t = \frac{1}{2}$。在區間 $[-\sqrt{2}, \sqrt{2}]$ 內，離對稱軸最遠之端點為 $t = -\sqrt{2}$：
      $$m = -(-\sqrt{2})^2 + (-\sqrt{2}) + 1 = -2 - \sqrt{2} + 1 = -1 - \sqrt{2}$$（2 分）
    故最大值為 $\frac{5}{4}$，最小值為 $-1 - \sqrt{2}$。
