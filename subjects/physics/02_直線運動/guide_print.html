第 1 頁 / 共 2 頁
一、 質點、位置、位移與路徑長核心觀念 向量 vs 純量
位移 (Displacement, $\Delta x$)[向量]
$\Delta x = x_2 - x_1 = x_{\text{末}} - x_{\text{初}}$
• 僅取決於初位置與末位置，與運動路徑完全無關。
• 正負號表示方向：$\Delta x > 0$ 正向，$\Delta x < 0$ 負向。
路徑長 (Distance, $\Delta \ell$)[純量]
$\Delta \ell \ge |\Delta x| \quad (\text{恆正或為零})$
• 運動軌跡之總長度。
• 僅當質點單向不折返直線運動時，$|\Delta x| = \Delta \ell$。
二、 速度、速率、加速度與微積分函數關係 微積分關係
• 平均速度：$\bar{v} = \frac{\Delta x}{\Delta t} = \frac{x_2 - x_1}{t_2 - t_1}$ （方向與位移相同）
• 瞬時速度：$v = \frac{dx}{dt} = \lim_{\Delta t \to 0} \frac{\Delta x}{\Delta t}$ （切線斜率）
• 平均速率：$v_{\text{avg}} = \frac{\text{總路徑長}}{\text{總時間}} = \frac{\Delta \ell}{\Delta t}$ （純量，折返時 $v_{\text{avg}} > |\bar{v}|$）
• 平均加速度：$\bar{a} = \frac{\Delta v}{\Delta t} = \frac{v_2 - v_1}{t_2 - t_1}$ （方向與速度變化量 $\Delta v$ 相同）
• 瞬時加速度：$a = \frac{dv}{dt} = \frac{d^2x}{dt^2}$
★ 判斷快慢：$a \cdot v > 0$ 同向為加速；$a \cdot v < 0$ 反向為減速！
三、 直線運動三大圖形物理意義對照矩陣（點、割線、切線、面積） ★ 解題核心
圖形種類 點座標 $(t, y)$ 兩點割線斜率 切線斜率 與時間軸所圍面積
$x-t$ 圖
(位置-時間)		 該時刻之位置 $x$ 時段內之平均速度 $\bar{v}$ 該瞬間之瞬時速度 $v$ 無常用物理意義
$v-t$ 圖
(最重要的圖)		 該時刻之瞬時速度 $v$ 時段內之平均加速度 $\bar{a}$ 該瞬間之瞬時加速度 $a$ 位移 $\Delta x$ ($t$軸上方為正，下方為負；總路徑長為面積絕對值和)
$a-t$ 圖
(加速度-時間)		 該時刻之瞬時加速度 $a$ 無常用意義 躍度 (Jerk) 速度變化量 $\Delta v = v_{\text{末}} - v_{\text{初}}$
(注意：面積是 $\Delta v$，非末速！)
四、 等加速度直線運動四大公式與推導 必背無死角
【公式一 · 速度時間式】
$$v = v_0 + at$$
推導：由 $a = \frac{\Delta v}{\Delta t} = \frac{v - v_0}{t} \implies v - v_0 = at \implies v = v_0 + at$。
【公式二 · 位移時間式】
$$S = v_0 t + \frac{1}{2} a t^2$$
推導：$v-t$ 圖梯形面積 $S = \frac{(v_0 + v)t}{2} = \frac{[v_0 + (v_0 + at)]t}{2} = v_0 t + \frac{1}{2}at^2$。
【公式三 · 速度位移式（無時間）】
$$v^2 = v_0^2 + 2aS$$
推導：由 $t = \frac{v - v_0}{a}$ 代入 $S = \frac{v + v_0}{2} \cdot \frac{v - v_0}{a} = \frac{v^2 - v_0^2}{2a} \implies v^2 = v_0^2 + 2aS$。
【公式四 · 梯形平均速度式】
$$S = \frac{v_0 + v}{2} \cdot t = \bar{v} \cdot t$$
推導：等加速度運動全程平均速度恰好等於時間中點速度：$\bar{v} = v_{t/2} = \frac{v_0 + v}{2}$。

五、 初速為零（$v_0 = 0$）四大特殊比例推論與中點速度 快速解題技巧
1. 等時間間隔累積位移比 $S_1 : S_2 : S_3 : \dots : S_n = 1^2 : 2^2 : 3^2 : \dots : n^2 = 1 : 4 : 9 : \dots : n^2$
2. 等時間間隔時段位移比 $\Delta S_1 : \Delta S_2 : \Delta S_3 : \dots : \Delta S_n = 1 : 3 : 5 : 7 : \dots : (2n - 1) \quad$ (連續奇數比)
3. 連續相等位移累積時間比 $t_1 : t_2 : t_3 : \dots : t_n = 1 : \sqrt{2} : \sqrt{3} : \dots : \sqrt{n}$
4. 連續相等位移時段時間比 $\Delta t_1 : \Delta t_2 : \Delta t_3 : \dots = 1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2}) : \dots : (\sqrt{n}-\sqrt{n-1})$
5. 時間中點 vs 位置中點速度 • 時間中點速度：$v_{t/2} = \frac{v_0 + v}{2} = \bar{v}$ ； • 位置中點速度：$v_{S/2} = \sqrt{\frac{v_0^2 + v^2}{2}}$
★ 核心結論：無論加速或減速，恆有 $v_{S/2} > v_{t/2}$！
六、 常見重力運動模型與光滑斜面下滑 地表運動模型
1. 自由落體 ($v_0 = 0, a = g$ 向下)
• 著地時間：$t = \sqrt{\frac{2h}{g}}$
• 著地速度：$v = \sqrt{2gh} = gt$
• 落下高度：$h = \frac{1}{2}gt^2$
2. 鉛直下拋 ($v_0$ 向下, $a = g$ 向下)
• 速度公式：$v = v_0 + gt$
• 高度公式：$h = v_0 t + \frac{1}{2}gt^2$
• 速度位移：$v^2 = v_0^2 + 2gh$
3. 鉛直上拋 ($v_0$ 向上, $a = -g$ 向上)
• 頂點時間：$t_{\text{頂}} = \frac{v_0}{g}$ ； 最大高度：$H_{\text{max}} = \frac{v_0^2}{2g}$
• 全程時間：$T = \frac{2v_0}{g} = 2 t_{\text{頂}}$ （上升時間 = 下降時間）
• 速度對稱：通過同一高度時 $v_{\text{下}} = -v_{\text{上}}$
4. 光滑斜面下滑 (傾角 $\theta$, 長 $d$, 高 $h$)
• 下滑加速度：$a = g \sin\theta$
• 底端速度：$v = \sqrt{2gh}$ （與傾角 $\theta$ 無關，僅與高 $h$ 有關）
• 下滑時間：$t = \sqrt{\frac{2d}{g\sin\theta}} = \frac{1}{\sin\theta}\sqrt{\frac{2h}{g}}$
七、 一維相對運動與打點計時器實驗數據分析 探究與實作
一維相對運動核心定理
• 相對位置：$x_{AB} = x_A - x_B$
• 相對速度：$v_{AB} = v_A - v_B$
• 相對加速度：$a_{AB} = a_A - a_B$
• 相撞條件：同一時刻位置相同，即 $\Delta x_{AB} = 0$。
• 最近/避撞極值：相對速度等於零，即 $v_A = v_B$！
打點計時器紙帶分析法 (頻率 $f$)
• 打點週期：$T = \frac{1}{f}$ （$50\text{Hz}\implies 0.02\text{s}$）
• 中點瞬時速度：$v_n = \frac{x_{n+1} - x_{n-1}}{2T} = \bar{v}_{(n-1)\to(n+1)}$
• 逐差法求加速度：$a = \frac{\Delta x_2 - \Delta x_1}{(\Delta t)^2}$
若間隔 $k$ 個時段：$a = \frac{x_{m+k} - x_m}{k \cdot (\Delta t)^2}$
