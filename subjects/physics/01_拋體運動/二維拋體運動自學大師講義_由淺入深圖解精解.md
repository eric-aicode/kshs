## 第一章：二維運動的基石 —— 運動獨立性原理與伽利略思想實驗

### 1.1 為什麼可以把曲線「切」成兩條直線？
亞里斯多德曾認為：如果給物體一個水平的推力，物體會先沿著直線衝刺；當推力消耗殆盡後，物體才會「突然鉛直下墜」。
這種直覺在 17 世紀被**伽利略（Galileo Galilei）**以嚴密的實驗徹底推翻。

伽利略提出了革命性的觀念：**正交方向的運動互不干擾、各自獨立進行（Principle of Independence of Motions）**。

#### 核心規律：
在空間中取直角坐標系 $(x, y)$：
- 水平方向（$x$ 軸）：物體不受任何水平外力（$F_x = 0$），根據牛頓第一運動定律，加速度 $a_x = 0$，物體永遠保持**等速度直線運動**。
- 鉛直方向（$y$ 軸）：物體僅受向下重力（$F_y = mg$），根據牛頓第二運動定律，加速度 $a_y = g$（向下），物體永遠保持**等加速度直線運動（純自由落體）**。

### 1.2 伽利略等時頻閃思想實驗
想像在一座高崖邊：
- 球 A：自靜止純**自由落體**落下。
- 球 B：以極高的水平速度 $v_0 = 100\text{ m/s}$ **水平拋出**。

```
時間 t=0   ● A (自由落體)  ───────────→ v0  ● B (平拋)
          │                                  │
時間 t=T   ● A            ··················  ● B  (下墜 1h, 水平前進 v0*T)
          │                                  │
時間 t=2T  ● A            ··················  ● B  (下墜 4h, 水平前進 2v0*T)
          │                                  │
時間 t=3T  ● A            ··················  ● B  (下墜 9h, 水平前進 3v0*T)
──────────────────────────────────────────────────── 地面
```

**自學鐵律**：
> 不論 B 球的水平初速度有多驚人，**在每一個相同時刻，A 球與 B 球的高度完全相同！**
> 兩者必定在「完全相同的瞬間」撞擊地面！
> **水平速度只決定它能飛得多遠，絲毫無法延後它撞擊地面的時刻！**

## 第二章：水平拋體運動（平拋）—— 基礎建模、軌跡方程與二倍角切線定理

### 2.1 運動學基本方程系統
設拋出點為坐標原點 $(0, 0)$，水平向右為 $+x$，鉛直向下為 $+y$：

$$\begin{cases}
a_x = 0 \\
a_y = g
\end{cases} \implies
\begin{cases}
v_x(t) = v_0 \\
v_y(t) = gt
\end{cases} \implies
\begin{cases}
x(t) = v_0 t \\
y(t) = \frac{1}{2}gt^2
\end{cases}$$

#### 物理特徵值：
1. **落地時間**：由下落高度 $h$ 單獨決定：
   $$t = \sqrt{\frac{2h}{g}}$$
2. **水平射程**：
   $$x = v_0 t = v_0 \sqrt{\frac{2h}{g}}$$
3. **落地瞬時合速度**：
   $$v = \sqrt{v_x^2 + v_y^2} = \sqrt{v_0^2 + (gt)^2} = \sqrt{v_0^2 + 2gh}$$
   *（備註：由力學能守恆 $\frac{1}{2}mv_0^2 + mgh = \frac{1}{2}mv^2$，可直接一秒驗算！）*

---

### 2.2 二倍角切線定理（平拋最重要的幾何心法）

任取軌跡上一點 $P(x, y)$，考慮兩個夾角：
1. **速度偏角 $\theta$**（切線方向與水平線夾角）：
   $$\tan\theta = \frac{v_y}{v_x} = \frac{gt}{v_0}$$
2. **位移偏角 $\alpha$**（割線方向 $\vec{OP}$ 與水平線夾角）：
   $$\tan\alpha = \frac{y}{x} = \frac{\frac{1}{2}gt^2}{v_0 t} = \frac{gt}{2v_0}$$

兩者相比，立刻得到大考最核心的幾何定理：
$$\Large \tan\theta = 2\tan\alpha$$

```
   O ────────── Q (x/2) ────────── x (水平線)
    \               :             │
     \              :             │ y
      \             :             │
       \            :             │
        \ α         : θ           ▼
         \──────────:──────────── P (x, y)
          \         :           /
           \ 位移 S  :          / 切線速度 v
            \       :         /
```

#### 幾何意義：
- 在直角三角形中，$\tan\theta = \frac{y}{\Delta x} \implies \Delta x = \frac{y}{\tan\theta} = \frac{y}{2\tan\alpha} = \frac{x}{2}$。
- **定理**：**平拋運動中，任一點 $P$ 的速度切線反向延長線，必過該點水平位移的正中點 $(\frac{x}{2}, 0)$！**
- **應用場景**：在斜面平拋撞擊題中，只要畫出切線交於水平中點，三角形邊長比例立刻解開，省去解聯立方程式的大量計算！

## 第三章：斜向拋體運動（斜拋）—— 對稱美學與三大基本公式雙向推導

### 3.1 初速度分解與運動對稱性
設初速為 $v_0$，仰角為 $\theta$：
- 水平分量：$v_{0x} = v_0 \cos\theta$（等速度運動）
- 鉛直分量：$v_{0y} = v_0 \sin\theta$（鉛直上拋）

---

### 3.2 三大基本公式推導

#### 1. 飛行總時間 $T$
在最高點處，鉛直速度減為零：$v_y = v_{0y} - gt_u = 0 \implies t_u = \frac{v_0\sin\theta}{g}$。
由上升與下降之對稱性，總滯空時間：
$$\Large T = 2t_u = \frac{2v_0\sin\theta}{g} = \frac{2v_{0y}}{g}$$

#### 2. 最大飛行高度 $H$
利用鉛直方向之運動學第三公式 $v_y^2 = v_{0y}^2 - 2gH$，最高點 $v_y = 0$：
$$\Large H = \frac{v_{0y}^2}{2g} = \frac{v_0^2\sin^2\theta}{2g}$$

#### 3. 水平射程 $R$
水平方向在總時間 $T$ 內等速前進：
$$R = v_{0x} \cdot T = (v_0\cos\theta) \cdot \left(\frac{2v_0\sin\theta}{g}\right) = \frac{2v_0^2\sin\theta\cos\theta}{g}$$
利用二倍角公式 $2\sin\theta\cos\theta = \sin 2\theta$：
$$\Large R = \frac{v_0^2\sin 2\theta}{g} = \frac{2 v_{0x} v_{0y}}{g}$$

## 第四章：黃金推論 —— 互餘角射程相等與射程因子因式分解秒殺術

### 4.1 射程與高度之比神公式
$$\frac{H}{R} = \frac{\frac{v_0^2\sin^2\theta}{2g}}{\frac{2v_0^2\sin\theta\cos\theta}{g}} = \frac{1}{4}\tan\theta$$
移項整理得：
$$\Large \tan\theta = \frac{4H}{R}$$

#### 震撼結論：
1. **最大射程角**：當 $\theta = 45^\circ$ 時，$\sin 2\theta = 1$，水平射程最大 $R_{\max} = \frac{v_0^2}{g}$。此時 $\tan 45^\circ = 1 \implies \mathbf{R = 4H}$！
2. **射高比定仰角**：只要題目給出 $H$ 與 $R$ 的比例，即可立即得知發射仰角 $\theta$。例如：若射程是最大高度的 $4\sqrt{3}$ 倍，則 $\tan\theta = \frac{4H}{4\sqrt{3}H} = \frac{1}{\sqrt{3}} \implies \theta = 30^\circ$！

---

### 4.2 互餘角射程相等性質
因為 $\sin 2(90^\circ - \theta) = \sin(180^\circ - 2\theta) = \sin 2\theta$：
> **在相同初速 $v_0$ 下，兩個互餘的仰角 $\theta$ 與 $(90^\circ - \theta)$，其水平射程 $R$ 完全相同！**

```
高度 y
  ▲               ╭─────╮ (θ = 60°: 高拋，滯空時間久)
  │              ╭       ╮
  │             ╭         ╮
  │           ╭───╮      ╭───╮ (θ = 30°: 低射，迅速抵達)
  │         ╭─     ─╮  ╭─     ─╮
  └─────────┴───────┴──┴───────┴────────► x (同一射程 R)
```

#### 互餘雙拋神關係矩陣：
- 滯空時間相乘：$t_1 t_2 = \left(\frac{2v_0\sin\theta}{g}\right)\left(\frac{2v_0\cos\theta}{g}\right) = \frac{2}{g}\left(\frac{v_0^2\sin 2\theta}{g}\right) = \mathbf{\frac{2R}{g}}$！
- 滯空時間平方和：$t_1^2 + t_2^2 = \frac{4v_0^2}{g^2}(\sin^2\theta + \cos^2\theta) = \mathbf{\frac{4v_0^2}{g^2}}$！
- 最大高度相加：$H_1 + H_2 = \frac{v_0^2}{2g}(\sin^2\theta + \cos^2\theta) = \mathbf{\frac{v_0^2}{2g}}$！

---

### 4.3 軌跡方程的射程因子因式分解形
傳統軌跡方程：
$$y = x\tan\theta - \frac{g}{2v_0^2\cos^2\theta} x^2$$
提公因式 $x\tan\theta$：
$$y = x\tan\theta \left(1 - \frac{gx}{2v_0^2\cos^2\theta \cdot \tan\theta}\right)$$
因 $2v_0^2\cos^2\theta \tan\theta = 2v_0^2\sin\theta\cos\theta = gR$，整式化為：
$$\Large \mathbf{y = x\tan\theta \left(1 - \frac{x}{R}\right)}$$

**實戰威力**：
在籃球空心入網、網球越網、擲球過牆等題目中，只要知道水平射程 $R$ 與障礙物坐標 $(x, y)$，帶入此式可在 5 秒內直接求出仰角正切 $\tan\theta$！

## 第五章：斜面拋體運動 —— 旋轉坐標系大法與垂直撞擊條件

### 5.1 旋轉坐標系設定
設斜面傾角為 $\alpha$，物體以相對斜面夾角 $\beta$（相對水平仰角 $\theta = \alpha + \beta$）拋出：
- 將 $x'$ 軸設為**平行斜面向上**。
- 將 $y'$ 軸設為**垂直斜面向上**。

#### 加速度分解：
重力加速度 $g$ 鉛直向下，投影到旋轉軸：
- $a_{y'} = -g\cos\alpha$
- $a_{x'} = -g\sin\alpha$

#### 初速度分解：
- $v_{0y'} = v_0\sin\beta$
- $v_{0x'} = v_0\cos\beta$

---

### 5.2 核心解題條件
1. **落回斜面時間 $t_{\text{落}}$**：
   斜面即為 $y'=0$。由 $y' = v_{0y'}t - \frac{1}{2}(g\cos\alpha)t^2 = 0$：
   $$\Large t_{\text{落}} = \frac{2v_{0y'}}{g\cos\alpha} = \frac{2v_0\sin\beta}{g\cos\alpha}$$
2. **離斜面最遠處**：
   當垂直斜面的速度為零（$v_{y'} = 0$）時，物體離斜面最遠，**此時速度向量恰好平行於斜面**！
   $$t_{\text{最遠}} = \frac{1}{2} t_{\text{落}} = \frac{v_0\sin\beta}{g\cos\alpha}$$
   最大垂直距離：$d_{\max} = \frac{v_{0y'}^2}{2g\cos\alpha} = \frac{v_0^2\sin^2\beta}{2g\cos\alpha}$。
3. **垂直撞擊斜面條件**：
   垂直撞擊斜面，代表著地瞬間**沿斜面方向的分速度剛好減為 0（$v_{x'} = 0$）**：
   $$v_{x'} = v_{0x'} - (g\sin\alpha)t_{\text{落}} = 0 \implies v_0\cos\beta = (g\sin\alpha) \cdot \frac{2v_0\sin\beta}{g\cos\alpha}$$
   兩邊消去 $v_0$，整理得：
   $$\cos\beta = 2\tan\alpha \sin\beta \implies \Large \cot\beta = 2\tan\alpha$$
   這是一條著名的斜面垂直撞擊極值公式！

## 第六章：大三角形幾何向量法 —— 初速等速位移與自由落體疊加

拋體位移向量可直接拆成兩項幾何向量疊加：
$$\vec{r}(t) = (\vec{v}_0 t) + \left(\frac{1}{2}\vec{g}t^2\right)$$

```
          Q (若無重力前進至此)
         /│
        / │
 v0 * t/  │ 1/2 * g * t^2 (自由下墜)
      /   │
     /    │
    /  θ  ▼
   O ─────► P (實際落點)
       r (合位移)
```

在三角形 $\triangle OQP$ 中：
- 邊長 $OQ = v_0 t$（沿初速發射方向）
- 邊長 $QP = \frac{1}{2}gt^2$（鉛直向下）
- 邊長 $OP = r$（由起點指向落點的合位移）

**大考解題秒殺法**：
凡是遇到斜面邊界、懸崖或三角形幾何邊界，直接在 $\triangle OQP$ 中套用**正弦定理**：
$$\frac{v_0 t}{\sin\angle OPQ} = \frac{\frac{1}{2}gt^2}{\sin\angle POQ} = \frac{r}{\sin\angle OQP}$$
兩邊消去時間 $t$，一元一次方程直接求得飛行時間或初速，完全跳過二維直角坐標的聯立開根號！

## 第七章：拋體曲率半徑與法向/切向加速度本質剖析

任何曲線運動的向心加速度公式：
$$a_n = \frac{v^2}{\rho} \implies \Large \rho = \frac{v^2}{a_n}$$

### 7.1 軌跡頂點的曲率半徑
- 在最高點，切線速度純為水平：$v = v_0\cos\theta$。
- 重力 $g$ 鉛直向下，恰好與切線速度垂直，故**法向加速度 $a_n = g$**（切向加速度 $a_t = 0$）。
- 曲率半徑：
  $$\Large \rho_{\text{頂}} = \frac{(v_0\cos\theta)^2}{g} = \frac{v_0^2\cos^2\theta}{g}$$

### 7.2 拋出瞬間的曲率半徑
- 在起點，初速度大小為 $v_0$，仰角 $\theta$。
- 重力 $g$ 與初速夾角為 $(90^\circ + \theta)$，垂直於初速的分量為**法向加速度 $a_n = g\cos\theta$**。
- 曲率半徑：
  $$\Large \rho_{\text{初}} = \frac{v_0^2}{g\cos\theta}$$

### 7.3 頂點與起點曲率半徑之比
$$\frac{\rho_{\text{頂}}}{\rho_{\text{初}}} = \frac{\frac{v_0^2\cos^2\theta}{g}}{\frac{v_0^2}{g\cos\theta}} = \Large \cos^3\theta$$
這是各大物理競賽與分科測驗最愛考的立方比結論！

## 第八章：經典相對運動 —— 獵人打猴子模型與兩物空中相撞

### 8.1 猴子為什麼必死無疑？
獵人拿槍對準樹上的猴子，扣動扳機的瞬間，猴子受驚鬆手自靜止下落。

#### 慣性系推導：
- 子彈水平位置：$x_B = v_0\cos\theta \cdot t$。
- 猴子水平位置：$x_M = d$。
- 當子彈到達猴子鉛直下方時，時間 $t = \frac{d}{v_0\cos\theta}$。
- 子彈高度：$y_B = v_0\sin\theta \cdot t - \frac{1}{2}gt^2 = d\tan\theta - \frac{1}{2}gt^2$。
- 猴子原高度 $H_0 = d\tan\theta$；猴子掉落後之高度：$y_M = H_0 - \frac{1}{2}gt^2 = d\tan\theta - \frac{1}{2}gt^2$。
- **結論**：$y_B(t) = y_M(t)$！兩者高度完全相同，精準命中！

#### 猴子非慣性系推導（高維降維思維）：
進入自由下落的猴子參考系：
- 猴子具有向下的加速度 $g$。
- 引入等效慣性力，宇宙中所有物體均疊加一個**向上的慣性加速度 $+g$**。
- 重力加速度 $-g$ 與慣性加速度 $+g$ 完美抵消，**猴子眼中的重力為 0**！
- 子彈在猴子看來做**等速度直線運動**，沿著原本槍管的直線路徑直奔猴子而來！
- 因此，只要初速足夠讓子彈在落地前到達猴子處，命中率是 $100\%$！

### 💣 七大易錯陷阱
1. **陷阱一**：誤認斜拋最高點速度為 0（正解：只有 $v_y=0$，合速度 $v=v_{0x}=v_0\cos\theta$）。
2. **陷阱二**：誤認最高點加速度為 0（正解：拋體全程加速度皆為重力加速度 $g$，方向鉛直向下）。
3. **陷阱三**：懸崖平拋或斜拋落地盲套 $R = \frac{v_0^2\sin 2\theta}{g}$（正解：兩端不等高時嚴禁套用此式，必須老實用 $\Delta y$ 解 $t$）。
4. **陷阱四**：混淆速度切線角與位移偏角（正解：$\tan\theta_{\text{速}} = 2\tan\alpha_{\text{位}}$）。
5. **陷阱五**：斜面拋體未分解加速度（正解：旋轉坐標系下，$a_{x'} = g\sin\alpha, a_{y'} = g\cos\alpha$）。
6. **陷阱六**：動量變化量以為要分解計算（正解：$\Delta \vec{p} = m\vec{g}\Delta t$，永遠純鉛直向下，與水平運動完全無關）。
7. **陷阱七**：誤認水平初速越快下落時間越長（正解：鉛直下墜時間由高度 $h$ 單獨掌控）。
